通义千问（阿里云百炼）：怎么申请

打开官方平台

  1. 登录阿里云，按要求完成实名认证，进入百炼控制台。
  2. 选择华北2（北京）地域并开通模型服务，在凭据管理创建 API Key；如使用其他地域，必须改成对应地域的接口地址。
  3. 给业务空间开通千问模型权限，检查免费额度或按量计费余额；编程套餐凭证不能用于这里的通用接口。
  4. 选择通义千问，粘贴凭证，默认使用北京原有兼容地址和 qwen-plus。也可在“模型与地址”改为控制台提供的业务空间专属地址。
  5. 点“测试连接”，成功后点“进入首页”。

凭证只保存在本机加密资料中，请及时做备份。换服务商也需要重新测试。不要将凭证发给老师或贴进聊天。
