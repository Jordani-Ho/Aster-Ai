其他 OpenAI 兼容接口：怎么申请

  1. 向您选择的服务商申请 OpenAI Chat Completions 兼容接口，按其官方要求注册、开通计费并创建 API Key。
  2. 复制服务商官方给出的 HTTPS 根地址（不包含 /chat/completions）和准确模型名称。
  3. 回到知衡选“其他 OpenAI 兼容接口”，填写接入凭证、接口地址和模型名称。不要填写聊天网页地址或本机地址。
  4. 如果服务商不允许浏览器直连，请让社区部署者将完整 /chat/completions 地址加入网关代理允许清单，然后重试。
  5. 点“测试连接”，成功后点“进入首页”。

凭证只保存在本机加密资料中，请及时做备份。换服务商也需要重新测试。不要将凭证发给老师或贴进聊天。
