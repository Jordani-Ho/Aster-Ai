豆包（火山方舟）：怎么申请

打开官方平台

  1. 登录火山引擎控制台，按要求完成实名认证，进入火山方舟的北京地域。
  2. 开通模型服务并确认计费账户可用，在 API Key 管理创建并复制凭证。
  3. 在推理接入点页面创建或打开可用的豆包文本模型接入点，复制接入点 ID（ep- 开头），确认凭证有该接入点权限。
  4. 回到知衡选择豆包，粘贴凭证和接入点 ID。这里使用通用按量调用接口，不用 Coding Plan 地址。
  5. 点“测试连接”，成功后点“进入首页”。

凭证只保存在本机加密资料中，请及时做备份。换服务商也需要重新测试。不要将凭证发给老师或贴进聊天。
