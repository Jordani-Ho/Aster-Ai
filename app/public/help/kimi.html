Kimi（月之暗面）：怎么申请

打开官方平台

  1. 登录 Kimi API 开放平台，按要求完成账户开通。
  2. 进入 API Keys 创建并复制接入凭证；聊天会员不是 API 额度。
  3. 检查账户额度并按需充值。中国站和国际站凭证与地址可能不同，请按创建凭证的平台文档选择。
  4. 回到知衡选择 Kimi，粘贴凭证。默认中国站接口；国际站请在“模型与地址”填写国际站的地址。
  5. 点“测试连接”，成功后点“进入首页”。

凭证只保存在本机加密资料中，请及时做备份。换服务商也需要重新测试。不要将凭证发给老师或贴进聊天。
