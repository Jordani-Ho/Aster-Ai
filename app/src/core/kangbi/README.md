# 康币观察地基（V2-04）

生产规则在 `domain/tcm/kangbi-rules.json`，所有数值均为 null。没有康币自动写账或余额显示入口；没有充值购买康币、币种换算或对外连接实现。`KangbiEvent` 定义 create/flow/decline，`KangbiExternalConnection` 仅为未来发布汇总的类型口。

`recordObservation` 只记录明确提供的练习天数、老师占用分钟、问诊次数与三方评价（teacher/self/measurement）。缺评价是 null，不能当零或猜测；量表与运营权重尚未定，测试样例不代表运营规则。相同 id 重送不重复记，改内容要新 id。

学生打卡按“本人/家人 + 老师 + 本地日期”记一天观察，重复上报不叠加；老师远程签字后按签名事件 id 记实际打开到签字的设备计时时长，三方评价未测则保留 null。时间只是设备测量，不能视为精确工时或自动收费依据。其他采集端以后通过此 API 提供真实评价。

`kangbiSummary` 对外只给人数、观察次数、天数、分钟数与三方数值的计数/合计，不返回名字、公钥、原记录或个人明细。`kangbi-observations` 是本机个人观察记录，**长期保留、不受保留期限影响**（V2-05 起列入长期集合：只有计数与评分、没有内容，是将来给康币定值的依据）。钱账不导入本模块，观察数据不产生钱账交易。
