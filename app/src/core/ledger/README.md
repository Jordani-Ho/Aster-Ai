# 钱账（V2-04）

复用老师签名链、学生异议与对账控制器，改记真实货币。金额是 ISO 币种最小单位的安全整数；同一本账不能混币种。余额 = 充值 + 赠送钱 − 扣费 − 退款，可欠费；退款不超过累计充值减累计退款，赠送钱不能退成现钱。已删除第一版 Pricing/每康币价格接口，不做数据迁移或兼容层。

- `types/chain/verify`：四类事件、货币、链 prev、成熟 nostr-tools 签名；验签重算哈希并重建对象，防缓存 Symbol（错题本 E-004）。累计金额也检查安全范围。
- `sync/runtime`：链和出站消息同一 IndexedDB 写入。recordBatch 验整批后一次落盘，confirmationId 保证重复确认不多记；重连/focus/online/visibilitychange 自动对账补送。学生只读取本人参与的老师钱账；家人继续一家一本账。
- `money.ts`：精确十进制到最小单位、BigInt 辅助展示、纯真人确认入口、按币种匿名汇总（人数/总量/流向）；不导入模型或康币。已有钱账币种优先于老师默认币种。
- `money-draft.ts`：只调用本人的现有文本模型，提示词在 prompts/teacher/money-entry.md；严格限制事件类型/金额字符串/家人/退款引用，拒绝模型指定币种、自由文本或其他字段。模型只返回草稿，不签字、不发送。
- `MoneyEntry/LedgerSettings`：老师给账本填一次本机称呼与币种，再说一句话生成草稿。确认前可取消；确认才入账。失败的原话持久化，恢复连接或回到页面重试草稿；已生成草稿重载不重复调模型，仍需本人确认。学生能看充值、赠送、扣费、退款和自己的余额，不显示康币余额。

钱不经系统支付，老师在社区外收款后确认记账。每条签名绑定师生、币种、金额、家人、prev 与可选确认编号。具体格式见 docs/schemas/money-ledger.md；异议与对账延续原协议和 7 天边界，未重定义退款/欠费政策。多标签/多设备同时写同一本账仍不支持，冲突时不自动选赢家。

新币种、金额语义及 confirmationId 是 B 类格式变更，交 Claude 审核。生产康币规则全 null，健康观察在独立 kangbi/，两本账没有互相换算或外部支付实现。
