# core/appointments · 预约

预约由本机 `appointments` 集合保存；中继只传现有 NIP-17 端到端加密信封。`createAppointmentInbox()` 校验方向和已认定的师生关系，按 `offerId` 幂等收消息。邀约固定两小时过期，状态只按任务卡允许的方向变化。容量按老师本地时区的真实时刻计算。

- 新邀约与排班校验都用 `core/schedule/appointments.ts` 的 `appointmentSlots()` 算可约时段。
- 学生通过 `replyToAppointment()` 接受或拒绝；老师确认容量后回确认。多发的一位若也接受，会收到“约满”并获得同一活动中的下一可约时段。
- 老师可在“今天”页记录已到或未到；排班保存前用 `appointmentsAffectedBySchedule()` 列出受影响的已确认预约，当前可选择保留原预约后保存。
- 老师在开馆基础工作中选择自动邀约或过目后发；复核模式离线时仍能保存本地草稿。
- 不接模型、没有中心预约库；离线状态留在本机，连上中继后由现有传输队列发送。

学生主动预约请求、排班变更时的“取消并通知”选项，以及向学生显示老师城市，尚未实现。
