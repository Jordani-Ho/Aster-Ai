# 身份

BIP-39 生成 12 词，默认简体中文，可选繁体中文、英文。恢复按简体、繁体、英文
取第一个校验通过的词表，记录在 Identity.language；不转换简繁，密码短语为空。
NIP-06 路径 m/44'/1237'/<account>'/0/0，本人 0，被照护者 1、2……。
createIdentity 底层接口也接受官方 24 词向量；restoreIdentity 界面接口只接受 12 词。

私钥、助记词仅存在页面内存；核对随机三个不同位置，成功才派生身份。
完成后清除助记词状态，退出时覆写私钥字节。JavaScript 字符串和垃圾回收不能保证
物理内存擦除。持久化由 M1-02 负责，本模块不连接中继。

测试包含两组官方 NIP-06 向量、三种词表随机往返及两条库调用交叉验证。
中文测试不是官方向量；所有测试数据均为合成数据。
