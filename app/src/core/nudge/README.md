# 学生督促（V2-27）

`runStudentNudges` 在打开、回前台、数据变化和每分钟钟点刷新时取本机材料；`chooseNudges` 只用作业、打卡、舌象日期、签字病历、预约和本人作息做规则判断，不调用模型。一次事件用 V2-21 的 `student-nudge` 本机模板任务串行落盘，`student-nudges` 留下提醒正文、时刻及之后是否观察到行动；睡觉行为不可实测，状态保持未知。老师或社区收不到督促记录。

话术只来自 `prompts/student/nudge.md` 的固定数据槽，模板和填入值都过禁用词检查。作业到点后 10 分钟首次提醒，当晚 19 点后且距首次至少 4 小时未做再提醒，之后每天到点后提醒；无前后两周有效作业量时不说数字。照镜子从本机首次使用或上次记录起连续 3 天没记录才提醒。复诊只认已验签病历里明确的“数字天后复诊”，否则用老师签名门面公布的间隔；两者都没有时不猜。邀约只在剩余 30 分钟内催一次，过期不催。

V2-34 按当前居住城市区分复诊话术：同城继续引导预约时间，异地提示发远程问诊；城市缺失按同城。新增话术仍经过同一禁用词校验。

本人作息的睡觉至起床时段只产生一次睡觉提醒，其他类型当时不出现在应用内，也不触发推送。浏览器开着时可经 `core/push` 对已订阅的本人发一条无内容网页通知；关闭后不能读取本机数据，因此不承诺后台准时推送。无需、也没有关闭督促的开关。
