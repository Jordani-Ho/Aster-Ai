## 邀请

老师以原身份签名 kind 27235 的邀请（NIP-98 风格，非普通 60 秒请求凭据）。content 固定 `aster.invite` v1，单个 u/method/expiration/nonce 标签，默认 7 天并可重复使用；u 绑定当前部署的 `/invite/redeem`。链接用 fragment 封装，不放查询串，不向第三方二维码服务发送。二维码用固定 qrcode@1.5.4（MIT，2024-08-05 发布）本机生成。

学生使用自己的普通 NIP-98 请求兑换，签名绑定本人及完整请求体；网关校验邀请者仍是现有成员、签名与期限，再原子登记请求签名人。成功后才在本机登记老师、打开原账本并保存学生角色；未发任何充值/赠送/扣费。格式、过期、非成员、错误部署或篡改统一显示邀请失效。邀请链接仅清理成功后的 fragment，失败可重试；本机身份不被失败邀请替换。

V2-36 请出后回来仍兑换老师新签的邀请；兑换成功后把邀请暂存在本机，连上加密中继发给老师验证。旧邀请不能恢复名单资格。已有基础信息保留，学生智能体督促从重新进馆当天计算。
