# V2-08 舌象读图（原 V2-03 抽象器）

只做“读图 → 特征 + 舌头框 + 偏色标记”，不保存、不裁剪、不清原图；统一入口是 `core/tongue` 的 `captureTongue`。时辰、节气和城市由调用者提供，不发给视觉模型。模块本身不导入 store、消息收发或照片处理函数。

- 调用 `readTongue` 前把字节的所有权交给 `TransientPhoto`；调用方必须清空 file input、释放 File/Blob/预览引用，不能保留副本。原图在 `captureTongue` 裁剪完成后当场清零，成功/失败/超时/不支持看图全部相同处理。当前没有全局图片缓存。
- 模型必须返回 `color,coatingColor,coatingThickness,shape,teeth,cracks,confidence,box,lightingNote`：`box` 是舌头外接框，0–1 相对坐标或 0–1000 整数坐标都接受（任一值大于 1 就整套按 1000 换算），多余字段忽略；`lightingNote` 只在光线/白平衡明显偏色时为 true。回复先去掉 ```json 围栏和前后说明再解析。找不到舌头/框不合格时提示“没拍到舌头，请靠近一点再拍”；模型回复解析不出来按“模型暂时连不上”处理。V2-20 起不再按“框占画面 5%”判定，改由调用方按裁剪后短边像素判断（阈值在 `domain/tcm/tongue-features.json`）。
- 只接受 PNG/JPEG/WebP，头部及 10 MiB 上限是输入格式检查，不能代替模型实际解码。V2-20 起正常入口（`core/tongue` 的 `captureTongue`）会先用 `processPhoto` 把照片规范成长边 ≤1600 的 JPEG、去掉 EXIF 再交给这里；只有测试或直接调用会见到其它类型。
- 领域取值、调色板和位置在 domain/tcm/tongue-features.json；校验、框校验和固定路径 SVG 在 domain/tcm/tongue.ts。看不清用 uncertain（旧记录里的 unknown 只读兼容并按不确定显示），未见用 []，有但位置不确定用 null。模型自由文本（围栏/说明会被剥掉，但内容仍要合格）、SVG、照片回显一律拒绝。固定几何示意不构成诊断，置信度也不是临床可信度。
- 默认调用本人已经配置的模型，不替换模型名，不借家里账户降级，不把图片送到网关代理。CORS/网络错误、超时和 5xx 由 V2-20 的失败分档自动重试一次，仍失败提示“稍后再拍”；HTTP 401/402/429 提示“看舌象的模型账户需要检查（额度或密钥）”；HTTP 400/415/422 给“请换用支持看图的模型”，包括参数不兼容的情况；这不是能力检测结论。
- JavaScript 字符串不可变，无法强制擦除已经形成的 base64/JSON 和浏览器网络栈的内部副本。这里只能清除应用可控引用和原字节，不声称完成浏览器堆栈取证级擦除，服务商的数据保留政策也不由本应用控制。

已接入 V2-01 普通存储、StudentToday（学生今天 → 照镜子）、ConsultPage：共用 `TongueCapture` 读取后只留舌头裁剪图（长边 ≤512），不创建原图预览；失败/卸载后不保存结果。家人数据用分片，模型配置读取代管人根存储。面诊页仍没有原图拍摄落盘入口。

问诊 `intake.tongues` 随草稿、待发包、老师收件、签字病历保存；裁剪图走既有附件通道，学生端与老师端都按保留期限删。接收、签字与显示均校验特征及固定 SVG，拒绝额外字段和任意 SVG。老师端起草页并排显示裁剪图与候选示意图，可逐项改值；模型原值与老师定值的差异只记计数进思想指纹。

测试：合成 PNG + 模拟视觉响应 + 可注入裁剪编解码（验收 1–2、6）；`app/src/core/tongue/tongue.test.ts` 覆盖不确定、偏色提示、指纹计数、镜子只留最新裁剪图与保留期限、级别设置；`e2e/abstractor.browser.mjs` 使用真实 Chromium 和真实页面组件。

V2-20：舌象拍摄链路先在 `core/tongue` 用 `processPhoto` 规范图片（≤1600 JPEG、去 EXIF），再调用本模块。失败分档与自动重试在 `core/tongue/failures.ts`：照片格式打不开、没拍到舌头/太远、模型暂时连不上（网络/超时/5xx，自动重试一次）、模型账户问题（401/402/429）；模型不支持看图沿用原提示并单独记一档。失败只在本机 `tongue-failures` 集合记类别，不存照片、不存模型原文。HEIC 等浏览器解不开的格式在送模型前就提示“这张照片的格式手机浏览器打不开……”，不会请求模型。
