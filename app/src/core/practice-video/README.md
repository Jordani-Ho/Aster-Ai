# 练习视频

每段使用 WebCrypto AES-256-GCM 的独立随机密钥和 IV，AAD 绑定老师、学生、作业及原片/练习角色。
SHA-256 先校验密文，再校验解密结果。引用中的密钥只能经现有 NIP-17 信封传给指定学生或回看老师。

文件服务只收到密文，不接触引用里的密钥。本机以 Uint8Array 放进 LocalStore 的二进制集合：
中继备份自动排除视频字节，备份文件包含。下载完整且校验通过后才写本机，不保留中断片段。
服务地址由当前社区配置提供，不采信来信提供的任意网址。

改稿只给模型作业文字，不发送视频引用；单纯改方仍保留同一作业的视频。重写作业时不把旧片关联到新作业，
界面提示重新添加。回看原片由学生显式再授权老师，老师不靠长久留存原片实现对照。
