# 药材库（V2-24）

老师和学生共用同一套本机库存核心；每个人的数据保存在自己的本机 `LocalStore`，不上传中心数据库。

- `herbs`：药材名、展示单位、库存与警戒线都按最小单位存整数。克、钱、两换算为 0.1 克；片、枚、个按整数计。
- `herb-ledger`：入库、开方扣减、盘点调整与作废冲回流水。每条余额更新和流水在同一个 IndexedDB 事务；幂等 key 防重复。
- `herb-settings/units`：老师确认的 1 钱、1 两折克配置。没配置时不猜。
- 同味药名经 NFKC 全角转半角并去空白后比较。同味药重复出现在方子里会先合并。
- 多味扣减在一笔本机事务内预核全部库存；任何缺货或不足都不写任何扣减流水。
- 有流水或非零库存的药材不能删除，只能停用；停用项不能入库或扣减。
- 老师选择备药时，面诊签字只尝试原子扣减库中有且剂量可解析的药；库存不足时整方不扣，剂量无法处理时跳过并在签字后提示。库存不会阻挡签字；不备药不扣不提示，库外药视为外面抓的。签名记录发送失败时按原流水冲回。远程开方不动老师库存。
- 学生只在远程问诊时自动附上有数量的药材快照；家人问诊和煎药都读写根身份的同一份库存。库存不实时同步，下一次远程问诊自然带上新数量。
- 学生端 `herb-advice` 任务按新签病历和本机库存生成库存对照、低库存与下一剂提醒；点“煎了一剂”由 `herb-brew` 任务调用原子扣减。两项都用规则，不调用模型，不把库存变更发给老师。
- 老师端收到的数量快照独立保存在 `teacher-herb-snapshots`，以问诊/病历 id 为键，不写入签名 `Encounter`。旧版只有“够 / 快没了”的快照仍可读取。

剂量不符合明确的“数字 + 单位”形式时不会猜，也不会扣库存。库存不足时批量扣减返回药名与差额。
