# V2-36 名单请出

老师在基础工作里可设连续 14–365 天未打卡请出，默认不设。老师智能体读已收到的坚持小结；旧小结缺少当前作业及最后打卡日时不据此请出。超过设定天数才发固定 `roster.leave` 加密通知，再从 `teacher-students` 删除学生并留下 `teacher-roster-leaves` 记录。发送失败不请出；病历、学生本机作业与已确认预约不删除。

请出记录挡住晚到的问诊、坚持小结和签字后的名单自动补入。学生收到老师的通知后，从“我的老师”移除，并保留本机旧病历可读。回来只走新的进馆邀请：学生连上中继发 `roster.join`，老师验证邀请签名、有效期与请出后的签发时间，再重新加入名单。旧邀请不能恢复资格。

`roster.test.ts` 用合成身份验证天数边界、无作业豁免、自动通知、保留记录、旧消息与旧邀请重放。`e2e/flow.spec.ts` 经真实中继验证两端请出与重新邀请。

V2-38：学生填齐基础资料后经端到端加密发 `student.basics-ready`，仅携带称呼、性别、年龄、健康八字、城市。待发资料断线留存，连上后补发；老师按学生公钥和消息时间保存最新一份。资料若早于进馆消息到达，先暂存，验证邀请后才供面诊使用。
