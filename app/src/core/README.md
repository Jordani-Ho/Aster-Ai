# 核心模块

abstractor/：V2-03 内存照片抽象，视觉请求只用本人模型，结果经 tongue/ 普通存储与 intake/ 问诊流转；原图不落盘。

identity/：与领域无关的本地随机身份生成（V2 起无助记词/恢复/派生）。
store/：普通 IndexedDB 键值存储（V2 起不加密、不包裹身份），含家人分片。
llm/：与领域无关的模型客户端，支持社区网关（NIP-98 签名）、自有 API Key、本地模型地址三种来源。
redflags/：急症红线的本地确定性匹配引擎，规则从 domain/tcm/red-flags.json 读取；第二层模型复核只留接口。
ledger/：康币账本纯逻辑：只由老师写的记账链、学生签名的独立异议列表、余额与欠费、L2 退款校验。
record/：共用病历和问诊包类型，签字、面诊记录（M1-12，老师代录 intake）。
drafting/：按模板和只读医案起草、校验模型回复、过滤档位；提示词和领域模板在仓库对应目录。
intake/：学生采集：照片压缩、十问追问（模型整理只摘取学生原话，断网退回固定问句）、本地急症筛查、确认页核对、问诊包生成与草稿/副本保存。
homework/：本机作业排程、打卡和近 7 天完成统计，领域历法由 domain/tcm/calendar 提供。
push/：标准网页推送（Web Push + VAPID）的 Service Worker 注册、订阅/注销与提醒客户端。
不包含中医逻辑或中继通信。

transport/：社区中继NIP-42连接、NIP-17/44/59私信、过期及会话内重连去重。
inbox/：一个 transport 的收件分发（问诊包、单张照片、签字病历、坚持率、账本），老师问诊箱与附件校验、学生病历入库与作业导入。
wiring/：把 transport、收件分发、账本同步接成一条问诊链路，发送后统一提醒收件人。
adherence/：坚持率纯逻辑（连续天数、周坚持率、提醒判断、学生小结与老师排序）。
