# M1-03 八字与年龄换算

- 状态：待领
- 依赖：无
- 白皮书依据：§4.2

## 目标

在学生手机上，把出生时间和出生地换算成八字（四柱）和年龄。发给老师的只有换算结果，原始出生时间不离开手机。

## 范围

要做的：
- `domain/tcm/bazi/`：纯函数 `toBazi(birth, options)`，返回年柱、月柱、日柱、时柱（时辰未知时返回 `null`，并带标记“时柱缺”）。
- `ageAt(birthDate, onDate)`：返回周岁。
- 选项：
  - `trueSolarTime`：是否按出生地经度做真太阳时修正，默认关闭，由老师在模板里设置；
  - `ziHourRule`：23:00～24:00 算当天还是次日（“早晚子时”的两种流派），默认次日，由老师设置。
- 出生地：内置一份常用城市经度表（中国地级市和海外主要华人城市），用户从列表里选。

不做的：
- 大运、流年等进一步推算（老师需要时另开任务卡）；
- 界面（并入 M1-09）。

## 建议依赖

成熟的农历和八字开源库（例如 6tail 的 `lunar-javascript` 或其 TypeScript 版本）。施工者先核实许可证和维护状态，写进合并请求。

## 验收用例

样例必须取自权威万年历，并用**两个独立来源交叉核对**，写在 `domain/tcm/bazi/fixtures.json` 里，注明来源。**不得由 AI 自行编造样例。**

1. 至少 20 组样例全部正确，必须覆盖：
   - 立春前后各一天（年柱按立春换年，不按正月初一）；
   - 每个“节”交接前后（月柱按节气换月）；
   - 23:00 前后（两种子时规则各自正确）；
   - 闰月出生；
   - 海外出生（时区换算正确）。
2. 时辰未知时，返回三柱，并带“时柱缺”标记。
3. 打开真太阳时修正后，经度相差 15° 的两个城市，结果按约 1 小时的差距变化。
4. `ageAt` 在生日前一天和生日当天分别返回正确周岁。
