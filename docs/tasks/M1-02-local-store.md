# M1-02 本地加密存储层

- 状态：待领
- 依赖：M1-01
- 白皮书依据：§4.1、§4.4、§9

## 目标

为应用提供一个“只有本人能读”的本地存储：所有业务数据都经过它写入手机浏览器，落盘的只有密文。

## 范围

要做的：
- `app/src/core/store/`：基于 IndexedDB 的键值和集合存储接口（`put`、`get`、`list`、`delete`）。
- 加密：由私钥经 HKDF 派生存储密钥，用 WebCrypto 的 AES-GCM 加密每条记录，每条记录使用独立的随机数。
- 应用启动时调用 `navigator.storage.persist()` 申请持久化存储，并把结果显示在“设置 → 存储状态”里。
- 提供 `exportEncrypted()` 和 `importEncrypted()`，供 M1-06 备份使用。

不做的：
- 备份上传到中继（M1-06）；
- 任何业务数据结构（由各业务卡自己定义）。

## 已定事项（2026-10-16，PR #3 答复）

1. **测试依赖**：批准 `fake-indexeddb@6.2.5`（Apache-2.0，2025-11 发布），仅开发依赖，固定确切版本。**不用 6.2.6**：它在 2026-10-16 当天发布，距上一版隔了 11 个月，按 AGENTS.md 的新规则（发布满 14 天）暂不采用。
2. **导入 = 整体替换，不合并。**
   - `importEncrypted(file, { replace: true })`。本地已有数据且没有传 `replace: true` 时，直接报错。
   - 先在内存里校验全部记录：格式版本正确、公钥与当前身份一致、每条都能解密。全部通过后，才在**同一个 IndexedDB 事务**里清空并写入。任何一条失败，本地数据保持不变。
3. **值类型**：支持“可 JSON 序列化的值”和 `Uint8Array`（照片、语音）。`Blob` 由调用方先转成 `Uint8Array`。
   - 明文格式：1 字节类型标记（`0x00` 表示 JSON，`0x01` 表示二进制）+ 内容（UTF-8 JSON 或原始字节），再整体加密。
   - 记录的明文元数据里带 `bin: true/false`，供导出时筛选。
4. **加密与导出格式**：由施工者按以下约束实现，并在 `app/src/core/store/README.md` 里完整写出，审核时一并批准。
   - 存储密钥：HKDF-SHA256，输入为私钥（32 字节）；salt 为每台设备首次初始化时生成的 16 字节随机数，明文存在元数据里；info 为 `aster/local-store/v1`。派生出 AES-256-GCM 密钥，以**不可导出**的 CryptoKey 形式保存在内存中。
   - 每条记录使用 12 字节随机 IV；**附加认证数据（AAD）= `集合名 + "\u0000" + 键名`**，防止有人把一条密文挪到另一个位置后仍能解密。
   - 集合名和键名不加密，所以：集合名只能用固定的英文名；键名必须是随机 ID，并在运行时校验 `^[A-Za-z0-9_-]{1,64}$`。**键名里不得出现任何个人信息。**
   - 导出容器（JSON）：`{ format: "aster-store-export", version: 1, createdAt, owner: 公钥十六进制, kdf: { alg, salt, info }, cipher: "AES-256-GCM", includesBinary, records: [{ c, k, iv, ct, bin }] }`。记录**原样复制密文**，不重新加密。
   - `exportEncrypted({ includeBinary })` 默认为 `false`（M1-06 的中继备份用），导出文件时传 `true`。
   - 导入时遇到未知的 `format` 或 `version`，直接拒绝。

## 验收用例

1. 写入一条记录后，直接读取 IndexedDB 的原始内容，找不到任何明文片段。
2. 用错误的密钥读取时，报出明确的错误，不会返回乱码数据。
3. `exportEncrypted()` 导出后清空数据库，再 `importEncrypted()`，所有记录完全恢复。
4. 对同一条明文写入两次，得到的两份密文不同。
5. 在测试环境（fake-indexeddb）下全部用例通过，CI 中可以运行。
6. 把一条记录的密文复制到另一个键名下，读取时解密失败（AAD 生效）。
7. 导入的文件属于另一个公钥时，被拒绝，本地数据不变。
8. 导入的文件里有一条记录被篡改时，整体导入失败，本地数据不变。
9. JSON 值和 `Uint8Array` 都能原样存取；`exportEncrypted({ includeBinary: false })` 的结果里不含二进制记录。
10. 键名含中文或超过 64 个字符时，写入被拒绝。
