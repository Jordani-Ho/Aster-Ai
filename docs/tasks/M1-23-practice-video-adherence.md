# M1-23 练习视频与坚持率：帮学生把动作练成习惯

- 状态：待派（排在 M1-22 之后）
- 依据：发起人 2026-10-17 描述的一位老师的做法（`docs/product/two-agents.md`“平衡”与“坚持”）：老师为学生设计一套动作，学生在老师处学会；最后一天老师**拍下学生自己练习的视频**，让学生带回家对照练；有疑问时微信视频即时指导。病好得快，难在一周之后能否坚持。

## 目标

让“学生自己的练习视频”成为作业的一部分，让智能体每天帮老师盯着学生坚持，让老师一眼看出谁快坚持不住了。

## 范围

1. **拍练习视频**（老师端面诊工作台）：在某条作业上点“拍练习视频”，用手机摄像头录一段，或从相册选一段。本机压缩到 720p 以内、单段不超过 90 秒。视频随签字病历交还给学生，老师端照常诊毕即还、不留。
2. **传输**：视频超过中继单条 2MB 的上限，按约 1.5MB 切块，逐块加密发送，带序号和整段的 SHA-256 校验；全部到齐、校验通过才显示。参照 M1-15a 照片单发的做法。
3. **学生端作业**：作业卡片上显示“对照视频”，点开全屏播放，可以循环、慢放（0.5 倍）。视频加密存在本机，进备份。
4. **我练给老师看**（异步指导，省老师时间）：学生在作业上点“录一段我的练习”，发给老师；老师在远程工作台看到，可以回一句文字或一段语音。即时的视频指导仍然用微信，不在本产品里重做。
5. **坚持率**：
   - 学生端：镜子页的作业旁显示“已连续练习 N 天”；连续漏练 2 天时，第二天镜子页的建议里多一条温和的提醒（不说教，沿用 M1-19 的口吻）。
   - 老师端：“今天”页列出本周坚持率低于一半的学生，排在前面；远程工作台每位学生旁显示本周练习天数。
   - 试点指标导出（M1-15b）加第五列“作业坚持率”。
6. 家人账户（M1-22）同样适用：家长替孩子看对照视频、打卡。

不做的：应用内实时视频通话（用微信）；动作识别与自动纠错。

## 验收用例

1. 老师在面诊时给作业拍一段 60 秒视频，签字交还后，学生端作业里能播放；老师端查不到这段视频。
2. 一段 10MB 的合成视频分块发送，中途丢一块：学生端显示“视频还在路上”，补齐后可播放；校验不符的整段丢弃。
3. 学生录一段练习发给老师，老师回一句话，学生收到。
4. 学生连续 2 天未打卡：第三天镜子页出现提醒；老师端“今天”页把他排在前面。
5. 试点指标 CSV 多出“作业坚持率”一列，仍不含任何身份或内容。
