# 任务卡

每张任务卡是一个文件：`M1-03-bazi.md` 这样命名。一张卡对应一个分支、一个合并请求。施工规则见根目录 `AGENTS.md`。

## 任务卡模板

```markdown
# M1-xx 标题

- 状态：待领 / 施工中（施工者）/ 审核中 / 已完成
- 依赖：M1-yy
- 白皮书依据：§x.x

## 目标
一两句话。

## 范围
- 要做的
- 不做的（明确写出来）

## 验收用例
1. 给定……当……应该……
2. ……

## 完成记录
- 合并请求：
- 结果：
```
