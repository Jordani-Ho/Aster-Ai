# M1-19 学生端三页：镜子、问诊（对话式）、其他

- 状态：已派（DeepSeek，2026-10-17）
- 依据：`docs/product/two-agents.md`

## 范围

1. 底部三个标签：**镜子 / 问诊 / 其他**，首页是镜子。原有页面（作业、病历、康币、备份、推送、设置）全部收进“其他”。
2. **镜子页**：问候语 + 当日建议（M1-18）+ 天气一行 + 今天的作业打卡 + “拍今天的舌象” + 最近 14 天自评走势小图（可点 1～5 分）。
3. **问诊页（对话式）**：一个输入框（提示“按键盘上的🎤说话就行”）+ 相机按钮。AI 追问以对话气泡出现（复用 M1-09 的追问逻辑，最多 3 轮）；问完在对话里出现一张整理好的卡片，可点开改，一个大按钮“发给老师”。历史病历默认附带，不让学生选。
4. **压力**（发起人 2026-10-17 加：心理健康决定生理健康）：
   - 镜子页自评在“今天状态 1～5”旁加“今天压力 1～5”，各点一下；走势图两条线。
   - `core/mirror` 增加压力序列；`prompts/student/daily-mirror.md` 改为：每天固定有一条情志与放松的建议；对熬夜、打游戏等不说教、不禁止，只给更好的疏解办法；最近连续 3 天压力 ≥4 时，建议侧重放松。
   - 问诊包带上最近 14 天的状态与压力走势，老师端草稿卡片上显示一条小走势。
5. **急症**：只在对话里提示一句“您说的情况需要尽快去医院，请不要耽误”，**不显示电话号码，不拦截**（唯一例外：自伤类照常显示心理援助热线）；问诊包里打上 `redFlag` 标记（只给老师端看）。
6. 375px 宽截图三张，放 `docs/screenshots/`。

## 验收用例

1. 打开应用即是镜子页，一屏内能看到当日建议和今天的作业。
2. 问诊页从输入第一句话到“发给老师”，不超过 3 次点按（不含打字和追问回答）。
3. 输入急症描述：出现就医提醒，页面上没有任何电话号码，仍能发送；输入自伤类描述：显示心理援助热线；老师端收到的问诊带 `redFlag`。
4. 自评压力连续 3 天为 5 时，模拟模型收到的输入里带有压力走势，且提示词要求侧重放松；返回的建议里没有“不要”“禁止”开头的说教句（断言）。
5. M1-15b 的 e2e 改成新界面后仍全绿。
