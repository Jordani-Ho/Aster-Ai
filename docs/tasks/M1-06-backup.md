# M1-06 加密备份与恢复

- 状态：已派（Codex，接在 M1-05 之后）
- 依赖：M1-02、M1-05
- 白皮书依据：§4.4、参数表 P9

## 目标

网页应用的数据存在浏览器里，清缓存或换手机就会丢。本卡保证：只要记得 12 个助记词，数据就能恢复。

## 范围

要做的：
- **中继备份（默认开启）**：每天一次，把 M1-02 的 `exportEncrypted()` 结果作为应用数据事件上传到社区中继，每人只保留最近 3 份。备份内容是结构化数据：身份资料、病历文本、作业、打卡、康币账本、老师端的模板和医案。
- **照片不进中继备份。** 照片体积大，只在“导出备份文件”里包含。
- **备份文件导出**：每月提醒一次，生成一个加密文件，由用户保存到自己选的地方。文件里包含照片。
- **恢复流程**：输入助记词 → 从中继拉取最新备份 → 解密 → 写回本地存储；也可以从备份文件恢复。
- “设置 → 备份状态”显示最近一次备份的时间和结果。

不做的：
- 照片的云端备份（以后评估 Nostr 的 Blossom 文件存储协议）。

## 验收用例

1. 写入测试数据 → 备份到模拟中继 → 清空本地数据库 → 用助记词恢复 → 数据完全一致。
2. 连续备份 5 次后，中继上只剩最近 3 份。
3. 用别人的助记词无法解密这份备份。
4. 导出的备份文件可以在另一个浏览器里恢复，照片完整。
5. 备份失败（中继不可达）时，界面明确提示，并在下次打开应用时重试。
