# V2-10 观察：老师和智能体各说一句“这段时间怎么样”

- 状态：已派（DeepSeek，接在 V2-09 之后）
- 依赖：V2-04（`kangbi-observations`）、V2-05
- 依据：（原 Codex 康币定值方案已删，康币定义改见 `docs/proposals/康币定义.md`）；决策 2026-10-18“内测只观察、影子试算后由发起人拍板”

## 目的

现在的观察记录只有总数，看不出三方是不是在评同一段时间。本卡只补“同一段时间、三方各自一句话”，不算康币、不显示余额。

## 范围

1. **观察周期**：一位学生跟一位老师，从上一次签字到这一次签字算一段；第一次问诊从学生加入那天算起。
2. **老师一句**：签字页加一行四选一：“和上次比：改善 / 持平 / 变差 / 说不准”，不选也能签字（记为未评价，不是持平）。
3. **本人一句**：学生在镜子页随时可以记“这段时间自己感觉”四选一，也可以不记。**感受只留给自己的智能体**（总纲 三·学的三层）：只存在学生本机，不随问诊包发出，老师看不到，也不进老师端的观察记录。
4. **智能体一句**：学生智能体按这段时间的坚持率和舌象特征变化给同样四选一；数据不够时一律“说不准”。规则写在 `domain/tcm/observation-rules.json`，不调模型。
5. 老师和智能体的两句各自独立，签字前互相看不到；本人那一句永远只在学生本机。
6. 老师端写进 `kangbi-observations` 一条：`{周期起止, 有效坚持天数, 老师分钟, 老师一句, 智能体一句}`；学生端另存本人那一句，只在本机。都不含病历内容、照片。
7. **影子试算**：`core/kangbi` 加一个只读函数 `shadowRun(observations, candidateRules)`，输入候选数值，输出“如果启用，每人会有多少刻”的分布和总量。没有任何界面入口，只给技术合伙人做发起人那一页摘要用。

8. `domain/tcm/kangbi-rules.json` 的 `weights` 去掉 `self`，只留 `teacher` 和 `measurement`（仍为 null）；观察记录和 `shadowRun` 都不再有本人感受这一项（医纲：本人感受不进康币）。

## 验收用例

1. 一个周期里老师选“改善”、本人不选、智能体“说不准”，记录里分别是 改善 / 未评价 / 说不准。
2. 签字前学生端看不到老师的选择；老师端在任何时候都拿不到学生的自我感受（检查发出的问诊包和所有信封）。
3. `shadowRun` 用两套测试候选数值得出不同分布；生产规则仍全为 null，界面没有康币余额。
