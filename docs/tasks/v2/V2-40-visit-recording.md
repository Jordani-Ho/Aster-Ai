# V2-40 面诊全程录音、转文字、望诊拍照

- 状态：待派（**Codex**，接在 V2-38b 之后）
- 依据：决策 2026-10-29（语音转文字用浏览器自带的识别；患处原图进病历）；发起人内测实测（电脑上点话筒没有反应，面诊页只有一个文字框）
- 原则：原话一字不改地保留；整理是智能体的草稿，老师改过、签字才算数；原始材料用完即毁。

## 场景

学生坐下，老师点「开始录音」，师生当面对话问诊，全程录音。停止或中断时，原话已经转成文字，智能体按本馆病历模板整理成结构化的病历草稿，老师改、保存、签字。

- **望**：面诊中给舌苔、患处拍照。
- **闻、问**：基本都在录音里。
- **切**：老师搭脉后记下脉象（手写，或口述进录音）。

## 范围

### 1. 话筒按钮改成「开始录音 / 停止」

现在的话筒按钮只是把光标放进文字框，电脑上看起来没反应。改成：

1. 点一下开始，同时做两件事：
   - **转文字**：浏览器自带的语音识别（`SpeechRecognition` / `webkitSpeechRecognition`，连续识别、边说边出字）；
   - **录音**：`MediaRecorder` 录下全程，只存老师本机。
2. **语言**：默认普通话（`zh-CN`），面诊页可切粤语（`yue-Hant-HK`），记住老师上次的选择。
3. **不断档**：Chrome 静音一会儿会自己停止识别；录音期间自动重新开始，不丢字、不重复。
4. **录音中**：顶端有红点和计时；离开面诊页前要确认。
5. **停止**：老师再点一下，录音和识别都停，自动进入整理（第 3 条）。
6. **中断**：页面切走、锁屏、话筒被拿走、识别报错——停止录音，已转出的文字保留，自动进入整理；老师可以接着再录一段。
7. **不支持时不报错**：
   - 浏览器没有语音识别，或识别服务不可用（如中国大陆的 Chrome）：一行提示「这台设备不能自动转文字，录音照录；可以用输入法话筒或直接打字」，录音照常；
   - 没给话筒权限：一行提示怎么打开权限。
8. 文字框保留：老师随时可以打字补充。
   - **下一步该点的按钮高亮**（决策 2026-10-29）：还没录时「开始录音」最重；录音中「停止」最重；框里有没整理的文字时「整理」最重；整理过后「说完了，看草稿」最重。「说完了，看草稿」点不了时，旁边写还差什么（如「先整理，主诉还空着」）。
9. **转文字是可替换的一件工具**：面诊页只认四个动作——开始、出一句定稿、停止、出错。网页版接浏览器识别；正式使用时换成每位老师自己的微信小程序，接微信自带的语音识别。换外壳时只换这件工具，原话编号、整理、病历都不动。测试里的假识别器也接在这里。

### 2. 原话

- 识别出的每一句定稿（`isFinal`）按顺序编号、一字不改，存进这次面诊的本机草稿。
- 老师可以手改识别错字，改过的句子标「老师改」。
- 草稿页可以回放本次录音，方便核对错字。

### 3. 整理

- 每停一次，老师智能体就把这一段原话按本馆病历模板整理进**主诉、现病史、望、闻、问、切**各栏。
- 每一栏标出依据哪几句原话（序号）。沿用 V2-26 的整理与校验：没有依据的内容不许出现。
- 分多段录时，新原话接着编号，整理结果补进去，不覆盖老师已经改过的栏。
- 取代现在「第一句作主诉、其余塞进现病史」的做法。
- 模型不可用时，按现有关键词拆分兜底，提示一行。

### 4. 望：拍舌象、拍患处

望那一格里有两个按钮：「拍舌象」「拍患处」。手机上直接调后置摄像头；电脑上用摄像头或选文件。

- **拍舌象**：复用学生端的舌象抽象——只留特征值、示意图和只有舌头的裁剪图，原图当场清掉；看不准写「不确定」。结果进这次病历的舌象。
- **拍患处**：
  - 原图压缩：长边 ≤1600 px，每张 ≤400 KB；每次面诊最多 3 张（加密包上限 2 MB）。
  - 老师可给每张加一句说明（部位、样子）。
  - 患处照片不发给模型，望诊描述由老师写或口述。
  - 随签字病历加密发回学生，学生端病历里能看到；老师端签字发出后删掉原图，只留说明文字。

### 5. 切

照旧由老师记脉象：点格子手写，或口述进录音（如「脉弦细」会被整理进切）。

### 6. 用完即毁

签字发出后，老师本机删除本次的录音、逐句原话和患处原图。录音不发给学生，也不离开老师的设备（转文字时声音会经过浏览器的识别服务，见白皮书第 13 节）。

**消息**：签字病历增加患处照片（照片和说明），走现有附件通道；老版本的病历没有这个字段时照常收。

## 输入校验与边界（每条都要有测试）

- 用假的识别器驱动：静音后自动重启，原话不丢、不重复；识别报错后录音照录、提示一行、可以打字。
- 页面切走（`visibilitychange`）、话筒轨道结束：停止录音，已转出的文字保留并自动整理。
- 整理的每一栏依据序号都存在；没有依据的内容进不了草稿；老师改过的栏不被下一段覆盖。
- 患处照片超过 3 张、压缩后仍超大小：拒绝并说明。
- 舌象原图当场清掉，本机找不到。
- 签字后，老师本机找不到录音、逐句原话、患处原图；学生端病历里能看到患处照片和说明。

## 验收用例

1. 假识别器逐句吐出一段合成的普通话问诊对话：主诉、现病史、四格里是病历用语，每栏带原话序号。
2. 切到粤语后，识别语言是 `yue-Hant-HK`；重开面诊页仍是粤语。
3. 375 px 手机与 1280 px 电脑两种宽度：录音按钮、红点计时、「拍舌象」「拍患处」都看得见、点得到（核对按钮底色，接 #105 的教训）。
4. 合成图片（不是真人）走完拍患处 → 签字 → 学生端病历能看到 → 老师端原图消失。
5. 只用合成数据；CI 三项全过。
6. 真机（发起人）：电脑 Chrome 上真说一段，确认边说边出字、停止后整理进各栏。

## 不做

- 老师自己的模型转写、本机离线转写：以后再加成可选项。
- 学生端问诊的录音和转文字：照旧（V2-26）。
- 智能体看患处照片写描述。
- 微信小程序外壳：正式使用前另开卡。
