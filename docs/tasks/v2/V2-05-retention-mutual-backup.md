# V2-05 保留期限由老师定；师生互为备份

- 状态：已派（DeepSeek，2026-10-18，接在 V2-02 之后）
- 依据：决策 2026-10-18“保留多久由老师定”“师生互为备份”

## 范围

1. **保留期限**：老师在设置里定“记录保留多久”（默认 90 天，可选 30 天到 3 年）。这个设置随调养方案发给该老师的学生，学生端按老师的设置滚动删除自己的镜子记录、问诊卡片、作业打卡；老师端按同一设置删除医案。
2. **长期保留的只有沉淀**：调养方案（最新一版）、作业规则、老师的思想指纹（改稿习惯摘要），不受保留期限影响。
3. **互为备份**：学生换手机后，向老师请求“把我的记录发回来”；老师端自动回发保留期限内的该学生记录（老师不用操作）。老师换手机时，向名下学生逐个请求，学生端自动回发。
4. 删除每天在打开应用时执行一次，不需要后台任务。

## 验收用例

1. 老师设 30 天：第 31 天打开应用，31 天前的记录在两端都不见了；调养方案还在。
2. 学生清空浏览器后，打开老师的邀请链接重新进入，自动收回保留期内的记录。
3. 老师清空浏览器后，名下两位学生的记录被自动收回。
