# V2-13 老师端全在手机上用

- 状态：待派（DeepSeek，接在 V2-15 之后）
- 依据：发起人 2026-10-20：国内落地时老师和学生都用手机，电脑只当服务器

## 范围

1. 老师端每一页（今天、远程、面诊、管理）在 375px 宽的手机竖屏上都能顺手用：签字、改病历、舌象左右对照（窄屏时上下排或切换）、说一句话记账、改门面、邀请学生（二维码能直接分享）。
2. 页面不出现横向滚动；按钮不小于 44px；长病历分段折叠。
3. 老师和学生都能“添加到主屏幕”，像 App 一样打开。
4. 每页交一张 375px 截图到 `docs/screenshots/phone-teacher-*.png`。

5. **建馆第 5 步加一个“先进去看看”**（V2-15 遗留）：第一位学生迟迟没连上时，老师不至于卡在邀请页；点了直接进工作台，邀请还能在“管理 → 邀请学生”里继续。

不做的：微信小程序（等网页版内测稳定后再定）。

## 验收用例

1. 在 375px 手机视口里，老师从收到问诊到签字发出，全程不用缩放、不横向滚动。
2. 老师在手机上生成邀请二维码，学生用另一部手机扫码进入。
