## 施工原则（第二版新增）

- **代码越简单越好**。同样的功能，谁写得最少、最直白，就用谁的。
- 第一版里还能用的模块直接复用；用不上的整块删掉，不留开关、不留兼容层。
- 第二版没有真实用户的旧数据，**不做数据迁移**。
- 其余规则照旧见根目录 `AGENTS.md`（一卡一分支一 PR、先写测试、不自审、不合并）。
