# V2-23 进馆基础信息：学生智能体进入角色

- 状态：待派（**Codex**，接在 V2-21 之后，可与 V2-22 并行）
- 依据：决策 2026-10-23（学生进馆先填妥基础信息才能第一次问诊）；`docs/智能体架构.md` 第五节；旧版盘点第 7 节
- 原则：资料留在学生本机。老师端照旧只收到协议里已有的那几项（称呼、性别、年龄、八字、城市）和问诊时学生自己带上的既往史、用药过敏。

## 范围

学生打开邀请、接入模型之后，第一次问诊之前，填基础信息。必填项填完，“不舒服？告诉老师”才可用；其余可以填“无”或以后补。

| 项 | 必填 | 说明 |
|---|---|---|
| 称呼 | 是 | ≤30 字 |
| 性别 | 是 | 男 / 女 / 其他 |
| 出生日期 | 是 | 年月日 |
| 出生时辰 | 否 | 十二时辰之一，或“不知道” |
| 出生地 | 否 | 城市 |
| 居住城市 | 是 | 用于天时（替代问诊页上那个城市选择） |
| 西医诊断 | 否 | 可多条；留在本机（康币以后用），不进问诊包 |
| 既往病史 / 在用药 / 过敏 | 否 | 问诊时自动带进卡片，学生可改 |
| 作息 | 否 | 平时几点起、几点睡（学生智能体督促时用） |
| 家里的药材 | 否 | 跳到 V2-24 的学生药材库 |

家人子账户（M1-22）用同一张表，另加“与我的关系”。

## 输入校验（每条都要有测试）

- 出生日期不能晚于今天；年龄 0–120 岁。
- 家人关系与年龄要讲得通，讲不通就**拦住**并说明：父母、祖父母比本人年长（父母至少大 12 岁，祖父母至少大 30 岁）；子女、孙辈比本人年轻（同样的差距）；配偶、兄弟姐妹、其他不限。
- 时辰只能是十二时辰之一或“不知道”。
- 作息：起床、睡觉是合法的钟点。
- 改出生日期或时辰时，提示“会影响八字推算”，确认后才改；本机留一条修改记录（何时、旧值→新值）。
- 八字和年龄每次现算，不存成死值；没有出生日期就不推算，并明确说出来。

## 验收用例

1. 新学生：必填项不全时，“告诉老师”不可用，并写明还差哪项；填全后可用。
2. 出生日期选明天：被拒。给“父亲”填一个比本人晚的生日：被拒并说明。
3. 填了既往病史，第一次问诊的卡片里自动带上，学生可以改。
4. 老师收到的问诊包里，profile 只有原有的五项；没有出生日期、出生地、西医诊断。
5. 已有老用户升级：不拦已经在用的人，但首页提示补齐必填项。
6. iPhone 15 Pro 与华为两种宽度截图；CI 三项全过。
