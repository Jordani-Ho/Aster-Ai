## 范围

1. **部署对齐第二版**：`deploy/home/` 里的脚本、`compose.yaml`、`README.md` 按第二版核对一遍：
   - 去掉已删功能的残留（备份槽、30078、身份槽、passkey、种子成员白名单等）；
   - 中继按第二版的补丁构建（只有 `community_open`）；
   - `quick-start.sh` 用 Cloudflare 临时隧道一键起来，最后一行打印出可以直接在手机打开的网址。
   - README 删掉过时章节，只留第二版的步骤（发起人不留旧版本）。
2. **一页《内测怎么开始》**：`docs/内测怎么开始.md`，写给发起人本人，不写技术细节，一步一行：
   - 在家里电脑上怎么启动、怎么停；
   - 一台设备当老师、一台当学生（例如电脑和手机），怎么各自打开、怎么接入自己的模型（Kimi）；
   - 按顺序试这几件事，每件写清“点哪里、应该看到什么”：照镜子拍舌象 → 发问诊 → 老师起草签字 → 学生收到病历和作业、打卡 → 老师说一句话记账、学生看余额 → 老师改门面、学生看到新门面 → 清空学生浏览器、用换机链接认回 → 加一位家人、代家人问诊；
   - 遇到问题记在哪里（建议记在 `team/selftest-notes.md`，一条一行：日期、做了什么、看到什么、期望什么）。
3. 在一台干净的 WSL2 上按《内测怎么开始》从头走一遍，有截图的放 `docs/screenshots/selftest-*.png`。

不做的：固定域名、香港/东京服务器（第二步再说）；任何新功能。
