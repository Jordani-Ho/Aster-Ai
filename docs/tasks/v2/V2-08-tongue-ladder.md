# V2-08 舌象抽象一步步来：第一级（只留舌头裁剪图 + 候选特征，老师说了算）

- 状态：已派（DeepSeek，接在 V2-06 之后）
- 依赖：V2-03（抽象器）、V2-05（保留期限、思想指纹）
- 依据：决策 2026-10-18“抽象是学习的过程，不要一步到位”

## 为什么

V2-03 一步到位：拍完即变成特征值和 SVG，原图即删。但现在模型还看不准：
- 同一个舌象，不同老师判断不同；
- 齿痕深浅可能是错觉；
- 颜色受拍照光线影响；
- 自拍常把鼻子、半张脸拍进去，镜头远近不一。

所以抽象分级往上走，**每位老师各自一级一级升**：

| 级 | 留下什么 | 谁说了算 |
| :-- | :-- | :-- |
| 第一级（本卡） | 只有舌头的裁剪图（脸、鼻子裁掉）+ 模型给的候选特征（看不准就标“不确定”） | 老师 |
| 第二级（本卡一并做记录部分） | 同上，老师改过的特征记进这位老师的思想指纹 | 老师，模型跟着学 |
| 第三级（以后） | 只留特征值和示意图，不留裁剪图 | 模型，前提是与这位老师长期一致 |

原图仍然不存、不发；裁剪图认不出是谁，算第一层抽象，按保留期限删除。

## 范围

1. **拍前一句提示**：“请在自然光下拍，关掉美颜，舌头自然伸出。”
2. **裁剪**：视觉模型除了特征，再返回舌头所在的框（相对坐标 0–1）。应用用 canvas 只裁出框内部分，长边 ≤ 512 像素，JPEG。框太小（不到画面 5%）或找不到舌头，就提示“没拍清舌头，请靠近一点重拍”。裁剪后原图字节照旧当场清掉。
3. **候选特征可以“不确定”**：`domain/tcm/tongue-features.json` 每项都加一个取值 `uncertain`；模型认为光线偏色时加 `lightingNote: true`，界面显示“颜色仅供参考”。
4. **裁剪图随问诊包发给老师**：走现有的附件通道（`attachments`），不新造通道。学生端和老师端都按保留期限删。
5. **老师说了算**：老师起草页并排看裁剪图和候选特征，可以逐项改。签字病历里存老师定的值；模型原值和老师改值的差异，按“特征项：模型说 X，老师定 Y”只记**计数**进 `teacher-fingerprint`（不存图、不存学生身份）。
6. **级别是老师的设置**：`tongueLevel` 默认 1，本卡只实现 1；值 3 先不开放。
7. 镜子（学生自己每天照）同样留裁剪图和候选特征，但不走老师确认，界面写明“仅供自己对照”。

不做的：第三级；颜色校正算法；任何会存或发送原图的路径。

## 验收用例

1. 合成测试图（舌头 + 一块代表鼻子的色块）经处理后，存下的只有舌头框内的裁剪图，找不到鼻子色块的像素；原图字节已清零。
2. 模型返回的框只占画面 3%，提示重拍，不生成记录。
3. 模型把齿痕标 `uncertain`，界面显示“不确定”；老师改成“有”并签字，病历里是“有”，指纹里“齿痕：模型不确定→老师有”计数加 1。
4. 模型标 `lightingNote`，学生端和老师端都显示“颜色仅供参考”。
5. 裁剪图过了保留期限，两端都删掉，签字病历里的特征值还在。
6. 全仓搜索：没有任何代码把原图写进存储或发给中继。
