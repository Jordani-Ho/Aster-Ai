# V2-12 钱账第一次就能记：老师端首次建账和币种入口

- 状态：已派（DeepSeek）
- 依赖：V2-04、V2-11
- 依据：V2-11 内测走查发现的阻塞（`team/selftest-notes.md`）：全新环境老师端只看到“尚未登记账本”，币种选择只在已有账本里出现，账本只在签字时填了扣费才创建，学生在邀请时开的账本不会同步到老师端

## 范围

1. **老师端钱账页列出名下所有学生**（从 `teacher-students` 读），不管有没有账本。没有账本的显示“还没记过账”，点进去照样能用“说一句话记账”。
2. **第一次记账时建账**：老师在这位学生这里第一次点“确认入账”时，老师端建账本并记这一笔；学生端照现有同步收到。不在签字时偷偷建空账本。
3. **币种**：老师第一次记账时选一次币种，默认用老师上一次用过的币种；一本账建好后币种不再改（已有规则）。
4. 学生在邀请时开的空账本，不再是老师端建账的前提；老师端建的账以老师端为准，学生端收到后合并（同一师生只有一本）。
5. 去掉“尚未登记账本”这个死胡同提示。
6. 更新 `docs/内测怎么开始.md` 第五步，删掉“内测已知问题”那段。

## 验收用例

1. 全新环境：老师邀请一位学生，没有签过任何病历，直接在钱账页对这位学生说“收到小王 100，送 20”，确认后入账；学生端看到余额 120 和币种。
2. 第二位学生第一次记账时，币种默认是上一次用的。
3. 先在学生端开过空账本、再由老师端第一次记账：两边最后只有一本账，余额一致。
