## 验收用例

1. 每页 375px 截图和对应设计稿并排贴进 PR。
2. 老师：全新部署走完建馆五步；从“学生”进一位学生，点“开始面诊”能直接开始。
3. 学生：从邀请链接进馆 → 首页 → “不舒服？告诉老师”→ 三步发出；三步顶端都能看到就医提醒，发送不受影响。
4. 旧页面组件（旧管理页、旧邀请首屏、旧问诊页、旧“其他”页）在代码里搜不到。
