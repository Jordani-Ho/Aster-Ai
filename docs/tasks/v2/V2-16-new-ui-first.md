# V2-16 新界面第一批：老师今天 · 面诊 · 核对签字 · 学生首页

- 状态：已派（DeepSeek）
- 依据：决策 2026-10-21“进入交互设计阶段”；设计稿 `docs/design/00–04-*.png`（技术合伙人出稿，发起人 2026-10-22 认可“先开始，后面再调”）
- 原则：只重做界面层，`core/` 的逻辑不动；这几页的旧界面整块删，不留开关

## 范围

1. **新的外壳**（`00-页面地图.png`）：老师端底部三个标签“今天 / 学生 / 我的馆”；学生端“今天 / 记录 / 我”。本卡只把“今天”做成新样子；其余标签先把现有页面原样挪进去（老的“管理”整体放进“我的馆”，老的病历页放进“记录”），下一批再重画。旧的顶层导航（今天/面诊/远程/管理，镜子/问诊/其他）删掉。
2. **老师 · 今天**（`01`）：
   - 最上面一张卡“学生到了？”加一个“开始面诊”按钮：点了选学生（名单），选完直接进面诊；
   - “等您签字”：远程问诊列表，每条一行，点进核对签字页；
   - “学生动态”：一行字，谁几天没打卡（来自现有坚持率小结），其余人数。
3. **老师 · 面诊进行中**（`02`）：
   - 顶部：学生称呼、性别年龄、第几次面诊、天时；可展开的“上次”（证候、方子名、坚持几天、作业）。
   - **“您说，智能体记”**：第一版不做应用内语音识别，用一个大文本框，老师用手机输入法自带的语音输入说话；每说一段（停顿或点一下“整理”），智能体把文字拆进望、闻、问、切四格。语音识别以后作为可替换的技能再接。
   - 四格各自标来源：“您说的”（老师）、“学生说的”（学生问诊里来的）、“听到了，待您确认”（虚线框，智能体拆出来但老师还没点过）。点任意一格可以改。
   - 底部只有两个按钮：话筒（聚焦文本框、唤起语音输入）和“说完了，看草稿”。
4. **老师 · 核对签字**（`03`），面诊和远程问诊共用这一页：
   - 判断、方子、作业、医嘱、“和上次比”一块一块；草稿是虚线黄框，标“草稿 · 依据什么”（比如“照您上次加减”）；每块只有“改一改”“就这样”两个按钮。
   - 改方时比对上一版，自动写出“去了什么、加了什么”，并要求一句理由（已有规则）。
   - 底部“签字发出”：还有草稿时灰着，上面一行“还有 N 处草稿等您确认”。
5. **学生 · 首页**（`04`）：
   - 天时卡：时辰、节气，一句来自老师方案的话（没有方案时显示通用的节气建议，并写明不是老师给的）。
   - 照镜子：昨天的裁剪图和示意图并排，一个大按钮“拍今天的舌象”。
   - 今日作业：每项一行，下面一行小字是挂的习惯，右边一个 48px 的圆圈打卡；连续天数。
   - 最下面一行“不舒服？告诉某某老师”，点了进现有问诊流程。
6. **样子**：暖白底 `#faf8f3`，字 `#1f2a24`，老师端主色 `#2f5d4a`（学生端跟门面主题走），标题宋体、正文黑体，圆角 16–22px，每页只有一个颜色最重的按钮。**不要从 Google Fonts 加载字体**（国内打不开）：用系统字体栈（`"PingFang SC","Noto Sans SC","Microsoft YaHei",sans-serif`，标题 `"Songti SC","Noto Serif SC",serif`）。

不做的：学生 / 我的馆 / 记录 / 我 这几个标签的新样子（下一批）；应用内语音识别。

## 验收用例

1. 375px 手机：老师从“今天”点“开始面诊”→ 选学生 → 说（打）一段话 → 四格自动填上并标来源 → “说完了，看草稿”→ 逐块“就这样”→ 签字发出，全程不横向滚动、不缩放。
2. 草稿没确认完，“签字发出”点不了；确认完才能点。
3. 远程问诊从“等您签字”进去，用的是同一个核对签字页。
4. 学生首页四块一屏内看得到（作业多时作业区内部滚动）；打卡圆圈点一下变成对勾。
5. 每页交一张 375px 截图，和 `docs/design/` 里的稿子放在一起对比，PR 里并排贴出。
6. 旧导航和这几页的旧组件在代码里搜不到。
