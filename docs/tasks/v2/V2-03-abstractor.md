# V2-03 抽象器：照片 → 抽象图 + 特征，原图即删

- 状态：已派（Codex，2026-10-18，接在 V2-01 之后）
- 依据：决策 2026-10-18“隐私靠抽象化”“原始资料不保留”

## 目标

像相书里的面相图一样：拍下的照片立刻变成一张不分男女、没有杂讯的抽象图，加几项特征；原图随即删除，任何地方都不保存。

## 范围

1. **舌象**：用学生自己接入的模型（需要支持看图的那几家，如千问、Kimi、豆包的视觉模型；不支持看图的服务商给出明确提示）从照片里读出特征：舌色、苔色、苔厚薄、齿痕、裂纹、舌形（胖/瘦），以及置信度。特征的取值表放在 `domain/tcm/tongue-features.json`。
2. **抽象图**：用一张标准舌形示意图（SVG），按特征上色、画出齿痕和裂纹位置。不用照片的任何像素。
3. **原图即删**：照片只在内存里存在到模型返回为止；不写进存储、不进任何消息、不缓存。模型失败时也删除，并请学生重拍。
4. **面部标记**（可选，同一卡里做最简版）：学生在通用人脸示意图上点出痣、斑的位置，保存坐标；不拍脸。
5. 输出结构 `{ kind: 'tongue', features, svg, shichen, jieqi, city }`，交给镜子和问诊使用。

## 验收用例

1. 用合成舌象图和模拟模型：得到特征和 SVG；之后在 IndexedDB、内存缓存、待发消息里都找不到原图字节（断言）。
2. 模型失败：原图同样被删除，界面请求重拍。
3. 不支持看图的服务商：给出“请换用支持看图的模型”的大白话提示。
4. 同一组特征生成的 SVG 每次相同。
