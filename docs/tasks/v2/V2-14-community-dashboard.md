# V2-14 社区仪表盘：每个馆只交统计数，我们只看不改

- 状态：待派（DeepSeek，接在 V2-13 之后）
- 依据：发起人 2026-10-20：内测初期要像“治理委员会”那样看得到各馆的运行情况，但不改代码；技术合伙人建议只交不含内容的统计数（总纲：没有中心、感受只留给自己）

## 范围

1. **馆这边交什么**：每个部署（一座馆）每天汇总一次，只有计数和时长，例如：
   - 版本号、服务在线时长、出错次数（只记错误类型，不记内容）；
   - 当天收到的问诊数、签字数、签字平均用时、作业打卡数、舌象记录数；
   - 学生人数（只是一个数）。
   不含病历、舌象、钱账、公钥、名字、城市、IP。学生的本人感受永远不交。
2. **交不交由老师定**：老师“管理”页里一个开关“向社区分享运行统计”，默认开；关了就什么都不发。开着时，老师能看到“今天发出去的就是这几行数字”。
3. **我们这边看**：一页只读的“社区仪表盘”网页，列出各馆最近 30 天的这些数字。只读，没有任何能改馆、改设置、发消息的按钮。
4. 统计数走现有中继（一种新的信封，发给仪表盘的公钥），不另开服务器接口。仪表盘地址和公钥写在部署的 `.env` 里，留空就不发。

## 验收用例

1. 一座馆一天的统计信封里，用测试扫描找不到任何病历字段、公钥（除收发双方）、名字、城市。
2. 老师关掉开关后，第二天不发任何统计。
3. 仪表盘页上没有任何会改变馆的操作。
