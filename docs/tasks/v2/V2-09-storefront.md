# V2-09 老师门面第一步：门牌、主题、短介绍、预览

- 状态：已派（DeepSeek，接在 V2-07 之后）
- 依据：`docs/proposals/teacher-storefront.md`（Codex 方案，技术合伙人 2026-10-18 认可其三项建议）
- 依赖：V2-05、V2-07

## 范围（只做方案 §9 的第一步）

1. **门面配置**：一份 `storefront` 配置，只含：馆名、显示称呼、标志（可空）、主题（从几套现成主题里选，主色 + 背景）、短介绍（≤ 120 字）、欢迎语（≤ 40 字）。随邀请和调养方案发给学生，签名归老师本人身份。
2. **邀请首屏**：照方案 §3 的线框：标志、馆名、“某某老师邀请你”、短介绍、一个“开始使用”按钮、一句“不替代医院诊疗”。邀请核验失败或过期时显示“邀请暂不可用，请向老师要一个新链接”，不显示门面。
3. **日常页首的门牌**：镜子、问诊、其他三页的页首显示“馆名 · 老师称呼”。问诊页写“发给某某老师”；钱账写“在某某老师这里的余额”。
4. **老师改门面**：管理页“我的门面”：左边直接改上面几项，下边是学生视角预览；有模型时也可以一句话改（“馆名改成小黄运动馆，用蓝色”），智能体只改配置。点“用这个样子”才生效，保留“恢复上次样子”（只存上一版）。
5. **多位老师**：“其他 → 我的老师”里切换，默认回到上次用的馆；切换时收件人、方案、钱账一起切。
6. 断网时用上次收到的门面；没有门面就用简洁默认样式。

不做的：卡片重排、模板和提醒调整（留给“自我调整”）；自定义网页、独立域名、支付、评价、公开搜馆。

## 底线（测试要守住）

- 门面配置里出现任何文本都不能改变急症提示、草稿/已签状态、钱账币种的显示。
- 馆名相同不代表同一老师；归属只认签名身份。
- “用这个样子”不签任何健康内容，不记钱。

## 验收用例

1. 同一套代码，两份配置（阿慈养生馆 / 小黄运动馆）出两种首屏，截图交 `docs/screenshots/`（375px 宽）。
2. 老师一句话改名换色 → 预览 → 用这个样子 → 学生下次同步看到新门面；点恢复回到上一版。
3. 伪造一份馆名“阿慈养生馆”但签名不是阿慈的门面，学生端不显示。
4. 门面介绍里写“保证治好”，界面照样显示“不替代医院诊疗”这一句，且急症提示照常出现。
5. 学生跟两位老师，切换后问诊收件人和钱账跟着切。
