# V2-27 学生智能体的督促

- 状态：待派（**Codex**，接在 V2-21、V2-25 之后）
- 依据：决策 2026-10-23（学生智能体以我为主改变不良习惯，不惯着、不顺着，不担心卸载；守线：不撒谎、不吓唬、不羞辱、不冒充老师）；`docs/智能体架构.md` 第七节
- 原则：督促要狠，话要真。第一版督促的话全部来自固定话术模板加真实数据，不用模型生成——这样从根上不会撒谎和吓唬。

## 范围

1. **督促什么**（挂在 V2-21 骨架上的学生端任务）：
   - 作业到点没打卡；
   - 连续几天没照镜子；
   - 该复诊了：老师方案里写了复诊间隔，或距上次面诊超过老师设的天数；
   - 老师发来邀约还没回（显示剩余时间）；
   - 到了作息里写的睡觉时间还在用手机（提醒去睡）。
2. **越拖越紧**：同一件事第一次温和提醒；当天没动再提醒；第二天起每天提醒，并把真实的坚持数据摆出来（例如“这周作业 2/7，上周 5/7”）。各级话术放 `prompts/student/nudge.md`，只能填数据槽，不能自由发挥。
3. **渠道**：应用内 + 网页推送（`core/push`）。
4. **学生能调什么**：不能关掉督促；只按本人作息里的睡觉时间不推送（夜里不吵他，反过来提醒他按时睡）。
5. **守线（代码检查）**：话术模板里不得出现诊断、病名、“严重后果”类词（维护一张禁用词表并测试）；只填真实数据，数据缺失时那一句不发。
6. **记录**：本机记每次督促和学生之后有没有动，只留在学生本机。

## 验收用例

1. 作业 8 点到点没打卡：8 点多一次温和提醒；晚上没动再提醒一次；第二天起每天一次并带上坚持数据。
2. 老师邀约剩 30 分钟：学生端收到催回复，带剩余时间。
3. 作息写 23:00 睡觉：23:00 后不推送其他督促，只提醒去睡。
4. 话术模板里加一句含禁用词：测试失败。
5. 坚持数据缺失：带数据的那一句不发，不编数字。
6. CI 三项全过。
