# V2-07b 换手机：家人随管理人一起认回

- 状态：已派（DeepSeek，紧接 V2-07 之后、V2-09 之前）
- 依赖：V2-07（本人认回）
- 依据：家人账户是核心场景（管理人带父母、孩子一起用）；V2-07 拆分（CTO 2026-10-18）

## 范围

1. 管理人被老师认回后（V2-07），管理人在新手机上重新添加家人，填同样的称呼。
2. 老师端凭旧的代管证明（kind 2732）找到旧管理人名下的家人，按称呼一一对上新家人身份，**不再让老师逐个点“是”**——管理人已被老师确认过，家人跟着管理人走。
3. 对上之后，老师端把保留期内旧家人的记录自动回发给新家人身份；钱账仍是一家一本，余额不变。
4. 称呼对不上的（比如改了称呼），在管理人那边提示“这位家人没找到原来的记录”，可以手动选一位旧家人对上；不选就当新家人。

## 验收用例

1. 管理人带两位家人清空浏览器 → 老师认回管理人 → 管理人重新添加两位同称呼家人 → 两人保留期内的记录自动回来，钱账余额不变。
2. 一位家人改了称呼 → 管理人看到提示，手动对上后记录回来。
3. 别的管理人添加同称呼的家人，拿不到这家人的记录。
