# V2-41 核对页是一份完整病历，方案由老师填

- 状态：待派（**Codex**，接在 V2-40 之后；两张卡都改面诊，V2-40 先合）
- 依据：发起人内测实测 2026-10-29——面诊点「说完了，看草稿」后，核对页只有「和上次比」和「签字发出」，看不到病历，也没有地方开方
- 原则：智能体只起草；没有草稿时，老师照样能把整份病历写完、签字。

## 现象与原因

1. **没接模型时，判断、方子、作业、医嘱整块消失**：`reviewBlocks` 只在有草稿或有内容时才出这几块；没接模型就没有草稿，老师无处开方。
2. **核对页不显示主诉、现病史**：面诊里整理好的原话和主诉，到核对页看不到。
3. **四诊只显示有内容的格**：空的格不出现。
4. **标题是「这位学生 · 核对」**：学生「华哥」已填好基础信息，称呼却没带进来。原因待查（可能是续上了基础信息到达前存的旧草稿）。

## 范围

核对页从上到下就是一份完整病历，老师在这里补全方案、签字：

1. **学生**：称呼、性别、年龄、居住城市（来自学生的基础信息）。
2. **主诉、现病史**：显示整理结果和依据的原话序号（V2-40 之后），可改。
3. **四诊**：望闻问切四格都显示；空的格写「未记」，点一下可填。舌象、患处照片的缩略图放在望里。
4. **判断**：证候、病机、辨证依据、摘要。
5. **方案**：治法、方子（药名、剂量、煎服法、服几天）、作业、医嘱。
6. **和上次比**、**签字发出**：照旧。

- 有模型草稿时：草稿照旧是黄虚线，每块「改一改 / 就这样」。
- 没有草稿时：4、5 两部分照样出现，是空白可填的格子，不是消失；页头一行提示「没接模型，智能体这次没有起草，请您直接写；接模型在设置里」。
- 签字的条件不变（这张卡不加新的必填项）。
- 修好称呼：核对页标题和病历里的称呼，用这位学生最新的基础信息；续上旧草稿时也补上。

## 边界（每条都要有测试）

- 没接模型：核对页有判断、方子、作业、医嘱四块，都能填；填一副方子签字，学生端收到的病历里有这副方子。
- 有模型草稿：行为和现在一样（回归）。
- 主诉、现病史在核对页可见、可改，改了的内容进签字病历。
- 四诊空格显示「未记」，填了才进病历。
- 学生基础信息晚于面诊草稿到达：续上草稿时标题是学生的称呼，不是「这位学生」。

## 验收用例

1. 浏览器用例（不接模型）：选学生 → 说一段 → 看草稿 → 写证候、开两味药、加一条作业 → 签字；学生端病历里四块都在。
2. 375 px 与 1280 px 两种宽度截图：从学生到方案一路看得见；空白格可点。
3. 只用合成数据；CI 三项全过。
