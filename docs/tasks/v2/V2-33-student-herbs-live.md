# V2-33 学生药材库：有数量、老师开方能直接调用、学生智能体来管

- 状态：待派（**Codex**，接在 V2-24 之后）
- 依据：决策 2026-10-25（学生药材库也要有具体数据，老师开方时可以直接调用；学生药材库由学生智能体管理）。本卡取代 V2-24 里“只发药名和够 / 快没了、不发数量”的口径。
- 原则：库存数据仍在学生本机；只发给他自己的老师（经中继、端到端加密），不进任何中心。

## 范围

1. **数量发给老师**：学生药材库的药名、数量、单位、警戒线，作为一份“家里的药材”快照发给当前老师（新 envelope `herbs.stock`）。
   - 何时发：学生库存有变化后（入库、煎药扣减、盘点）发一次；每次问诊包里也带最新快照。同一位老师只保留最新一份。
   - 家人代管：家人的药材库归在这位家人名下，老师端分开显示。
2. **老师开方直接调用**：
   - 老师端“一位学生”页和审方/面诊页，能看到这位学生家里的药材和数量。
   - 老师智能体起草方子时，把学生家里的库存当作材料：每味药标“家里有 X 克，够 N 剂 / 家里不够，差 X 克 / 要另抓”。只标出来，不改方子（方子由老师定）。
   - 开方签字后，在发给学生的方子上写明哪几味要另抓、各要多少。
3. **学生智能体来管**（挂在 V2-21 骨架上的学生端任务）：
   - 学生点“煎了一剂”，按方子自动扣自己的库存（V2-24 已有，这里改成由智能体任务执行，并在扣完后同步快照给老师）。
   - 快用完（低于警戒线）或按当前方子不够下一剂时，提醒学生补货，并列出要补哪几味、多少。
   - 老师签发了新方子：对照家里库存，告诉学生“这几味家里有，这几味要去抓”。
4. **老版本兼容**：老师端收到只有“够 / 快没了”的旧格式也照常显示。

## 输入校验与边界（每条都要有测试）

- 快照里的数量、单位、警戒线与 V2-24 同一套校验；格式不对整份丢弃，不影响问诊。
- 只收自己学生（或其家人）的快照；别人发来的不收。
- 单位换算按老师确认的钱/两配置；学生那边没确认换算时，只按克、片、枚、个计。
- 一剂不够：标“差 X 克”，不四舍五入成“够”。

## 验收用例

1. 学生入库 300 克黄芪：老师端“一位学生”页显示“黄芪 300 克”。
2. 老师方子里黄芪 30 克、当归 10 克，学生家里黄芪 300 克、无当归：起草页显示“黄芪 家里有 300 克，够 10 剂；当归 要另抓”；签字后学生收到的方子写明“当归要另抓 10 克”。
3. 学生点“煎了一剂”：库存自动扣减，老师端快照随之更新。
4. 学生黄芪剩 20 克、方子每剂 30 克：学生端提醒“黄芪不够下一剂，差 10 克”。
5. 家人代管：妈妈的药材在老师端显示在妈妈名下。
6. 两台手机真实中继 e2e：学生入库 → 老师端看到；CI 三项全过。
