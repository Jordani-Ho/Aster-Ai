# V2-02 天时：当地时辰、天文节气、两种时间显示、照镜子时辰

- 状态：已派（DeepSeek，2026-10-18，接在 V2-01 之后）
- 依据：结构图“天地人”“雾中的地图”两节；决策 2026-10-18“天地人”

## 范围

1. **时辰按当地太阳时**：根据学生档案里的城市经度，算当地真太阳时，再定时辰（复用第一版八字换算里的真太阳时）。城市未知时退回设备时区的钟点时辰，并在设置里提示补城市。
2. **节气按天文时刻**：节气是全世界同一时刻；先算出节气的天文时刻，再换算成学生所在地的当地日期（取代第一版“按北京时间”的做法）。
3. **两种时间显示**：一个配置项 `timeDisplay: 'shichen' | 'clock' | 'both'`，默认 `both`（如“辰时 · 8:20”）。这是表层配置，以后由智能体按主人习惯调整；本卡只做配置项和显示函数。
4. **照镜子时辰**：学生可选一个固定时辰（默认辰时）；到这个时辰提醒照镜子；镜子页的走势只拿同一时辰的记录对照，不同时辰的记录标出“时辰不同，不参与对照”。
5. 每条新记录带上 `{ shichen, jieqi, city }`。

## 验收用例

1. 洛杉矶（西经 118°）与北京（东经 116°）同一 UTC 时刻，时辰不同且各自正确（写出算例）。
2. 2026 年冬至：洛杉矶与北京的当地日期按天文时刻换算后各自正确。
3. `timeDisplay` 三种取值的显示结果正确。
4. 选了辰时后，一条午时的记录不进入走势对照，并带提示。
