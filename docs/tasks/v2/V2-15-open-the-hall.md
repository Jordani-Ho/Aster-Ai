# V2-15 建馆：老师第一次进来，一步一步开馆

- 状态：已派（DeepSeek，**排在 V2-13 之前**）
- 依据：发起人 2026-10-20 内测反馈：“管理”界面混乱；“建馆”是老师第一次和社区打交道，应该逐步引导；换门面、重装修、第 2 个及以后的邀请，等新馆开张后才出现

## 一、建馆引导（老师第一次打开时）

一屏一步，有“下一步”和“返回”，走到哪一步关掉再打开能接着走：

1. **接入自己的模型**（已有页面，放进引导里）。
2. **登记为社区老师**：粘贴部署口令。
3. **给馆起名**：馆名、称呼、选一套主题、写一句短介绍。右边或下面是学生看到的样子（复用 V2-09 的预览）。
4. **开馆**：一个大按钮“开馆”。点了以后，这座馆就算正式开张。
5. **邀请第一位学生**：开馆后立刻出现邀请链接和二维码。**这个邀请 1 小时内有效**，过期了显示“已过期”，旁边一个“重新生成”。第一位学生加入后，引导结束，进入正常的老师首页。

没走完引导之前，老师端只有这条引导，别的功能一律不显示。

## 二、管理页分阶段

- **开馆以前**：管理页只有建馆引导。
- **开馆以后**：管理页按这个顺序整理成几块，每块一个标题，默认折叠：
  1. 邀请学生（第 2 个及以后的邀请，沿用现有 7 天有效期）
  2. 我的门面（换门面、重装修）
  3. 钱账
  4. 记录保留多久
  5. 换手机
  6. 向社区分享运行统计（V2-14 做完后出现）
- 去掉现在管理页上重复、零散的入口；每个功能只在一个地方出现。

## 三、和其他卡的关系

- 本卡做完再做 V2-13（老师端手机化），V2-13 照本卡整理后的管理页适配手机。
- “开馆”是一个本机状态，加上门面签发；不新增服务器接口。

## 验收用例

1. 全新部署：老师第一次打开，只看到引导；走完五步，第一位学生用 1 小时内的邀请加入，老师端进入正常首页。
2. 第一个邀请超过 1 小时：学生打开看到“邀请暂不可用”；老师点“重新生成”，新链接可用。
3. 开馆前，老师端搜不到“换门面”“邀请学生（第二个）”“钱账”等入口；开馆后它们按上面的顺序出现在管理页。
4. 引导走到第 3 步关掉应用，再打开从第 3 步接着走。
5. 老学生（已开馆的馆）不受影响：现有开过馆的部署升级后直接进入正常首页，不重新走引导。
