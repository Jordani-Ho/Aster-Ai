# V2-26 问诊录音与两次整理

- 状态：本地实现完成，待审核与合并（**Codex**，接在 V2-21 之后）
- 依据：决策 2026-10-23（原话录音转给老师，学生端整理照旧，老师智能体再整理一次；老师认可后可不再收录音；学生智能体以老师智能体的整理为标准来校对；原始材料用完即毁）；医纲第二·四条；发起人实测（问诊卡把粤语原话和追问答案直接塞进病历）
- 原则：原话一字不改地保留；整理是智能体的草稿，学生核对后才发。

## 范围

**学生端**
1. **录音**：问诊“说一说”时可以按住录音（同时仍可用键盘话筒打字）。浏览器不支持录音时，只用文字，不报错。单段 ≤3 分钟，一次问诊合计 ≤10 分钟。
2. **两层内容**：
   - **原话**：学生打的字/键盘转出来的字，一字不改。
   - **整理**：学生智能体改写成病历用语，填进问诊卡各栏，标“智能体整理，待你核对”。
   - 去掉“整理内容必须是原话逐字子串”的旧规则，换成：整理的每一栏都要标出依据哪几句原话（记原话的序号）；没有依据的内容不许出现（代码检查）。
   - 追问的答案按“问—答”成对保存，不再塞进现病史。
3. **对标老师**：老师签字后回来的病历里带着老师智能体的整理；学生智能体保存最近 5 对“我的整理 / 老师的整理”，下次整理时作为参照。

**老师端**
4. **听录音**：问诊卡上有播放按钮。老师智能体用原话文字（不是录音）按老师的病历模板再整理一次，老师改、签字。
5. **用完即毁**：方案签字后，录音从老师手机上删除；学生端在问诊包发出并确认送达后删除自己的录音。
6. **开关**：老师基础模板里有“接收录音”（默认开）。关了以后学生端不再上传录音，只发原话和整理。

**消息**：问诊包增加 `originals`（原话列表）、`organized`（整理及依据序号）、`qa`（问答对）；录音走现有附件通道，类型白名单 `audio/mp4`、`audio/webm`、`audio/ogg`。签字病历增加 `teacherOrganized`。老版本的包没有这些字段时照常收。

## 输入校验与边界（每条都要有测试）

- 录音类型不在白名单、单段超时长、总时长超限、体积超限：拒绝并说明。
- 整理里有一栏没有依据序号、或依据的序号不存在：不能进问诊卡。
- 签字后，老师本机找不到这段录音；学生端送达后找不到自己的录音。
- 老师关掉“接收录音”后，新问诊包里没有录音附件。

## 验收用例

1. 用发起人实测那段粤语原话（合成文字，不用真人录音）：卡片“主诉”是简短的病历用语；原话完整保留在“原话”里；“会 / 没有”这类追问答案挂在各自的问题下。
2. 一段合成音频：老师端能播放；签字后从老师本机消失。
3. 学生连续三次问诊：第四次整理时，模型请求里带着前几次“我的 / 老师的”整理对照（最多 5 对）。
4. iPhone（`audio/mp4`）与华为（`audio/webm`）两种录音格式都能发、能放。
5. 只用合成数据；CI 三项全过。
