# M1-18 镜子页的核心：调养方案、当日建议、舌象与走势

- 状态：已派（DeepSeek，2026-10-17）
- 依据：`docs/product/two-agents.md`（学生第 1 页、老师第 3 页的调养方案）
- 本卡只做 `core/` 与 `domain/` 里的逻辑和数据，**不改界面**（界面在 M1-19、M1-20，等 M1-17 合并后做）。

## 范围

1. **调养方案**（`core/careplan/`）：老师给某位学生定制 `{ constitution: 体质（文字）, points: 调养要点[], avoid: 忌口与忌做[], updatedAt }`。老师签名（新 kind 2731，做法同 kind 2730 签字病历），经中继信封 `care.plan` 发给学生；学生端只接受“我的老师”名单里的人签的，新版本替换旧版本。
2. **通用节气养生**（`domain/tcm/seasonal.json`）：24 节气各一段简短的起居、饮食、情志要点，用于老师还没定制时。只写传统养生常识，不写具体药方。
3. **天气**（`core/weather/`）：按学生档案里的居住城市，从 Open-Meteo（免费、无需密钥）取今明两天的气温与降水；城市转坐标用 Open-Meteo 的地理编码接口。断网或失败时不显示天气，其他照常。新依赖不需要，直接 `fetch`。
4. **当日建议**（`core/mirror/`）：`dailyMirror({ carePlan, jieqi, weather, recentCheckins, recentSymptoms }) → { greeting, today: string[], trend }`。
   - 有网时经模型网关生成，提示词放 `prompts/student/daily-mirror.md`：口吻亲切、简短（不超过 5 条）、只谈起居饮食情志，不下诊断、不开药；
   - 断网或模型失败时，用调养方案 + 节气养生拼出固定格式的建议；
   - 同一天只生成一次，缓存在本机。
5. **舌象日记**（`core/tongue/`）：每天最多一张，复用 `intake/photo.ts` 压缩去 EXIF，加密存本机；提供按日期列出与“最近 30 天”的缩略列表。M1 不做自动分析。
6. **走势**：复用 M1-13 打卡记录，加一个“自评今天状态 1～5 分”的记录，输出最近 14 天的序列，供界面画趋势。

## 验收用例

1. 老师签发调养方案，学生端收到并替换旧版；陌生成员签发的被丢弃。
2. 没有调养方案、断网、模型失败三种情况下，`dailyMirror` 都能给出非空建议，且不含任何药名（用一个小药名表断言）。
3. 同一天调用两次只请求一次模型。
4. 天气接口失败时 `dailyMirror` 仍返回，`weather` 为空。
5. 舌象一天拍两张，只保留最后一张；照片无 EXIF。
6. 24 节气的养生文本齐全，每段不超过 120 字。
