# 内测怎么开始

给发起人本人看的一页说明。每一步都写清“点哪里、应该看到什么”。
遇到问题就记在 `team/selftest-notes.md`（一条一行：日期、做了什么、看到什么、期望什么）。

## 一、准备

- 电脑（Windows）开着，WSL 里的部署起起来；准备两台设备：**电脑当老师**、**手机当学生**（反过来也行）。
- 两台设备都能用手机：**老师一台手机、学生另一台手机**，电脑只当服务器；用电脑浏览器当老师也可以。
- 两台设备打开的是**同一个网址**。
- 各自有一个能用的模型钥匙（例如 Kimi 的 API Key）；没有的话先按提示接入，模型只用来整理文字/看图，不替老师签字。

## 二、在家里电脑上启动

1. 打开 WSL（Ubuntu）终端，进入仓库目录：
   `cd ~/projects/Aster-Ai/deploy/home`（具体路径按你放仓库的位置）。
2. 启动：`./quick-start.sh`
   - 第一次会构建镜像，等 10–30 分钟；以后大约 1–3 分钟。
   - **最后一行**是一个 `https://…trycloudflare.com` 网址，这就是手机要打开的地址。
3. 停止：在同一个目录执行 `docker compose --profile quick down`（数据还在 `data/`，不会删）。
4. 重新开始：再跑一次 `./quick-start.sh`。临时网址每次会变，以最后一行打印的为准。

## 三、让内测环境常驻（保活 / 固定网址 / 更新）

### 1. WSL 保活（整机重启后自己起来）

WSL 空闲约十分钟会被 Windows 回收，容器和临时隧道一起停。下面三条命令都是**你自己粘贴执行**，
脚本不替你注册任务、也不改电源设置；不想常驻可以跳过。

Windows 的 PowerShell（普通用户即可）执行一次，登录 Windows 时自动把 WSL 拉起来：

```powershell
$action = New-ScheduledTaskAction -Execute 'wsl.exe' -Argument '-d Ubuntu -e bash -lc "while true; do sleep 300; done"'
$trigger = New-ScheduledTaskTrigger -AtLogOn
Register-ScheduledTask -TaskName '知衡-保活-WSL' -Action $action -Trigger $trigger -Description '保持 WSL 与知衡内测容器常驻' -Force
```

电源设置（接通电源时不睡眠；显示器可以照常关）：

```powershell
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
powercfg /change monitor-timeout-ac 15
```

整机重启后的验证（在 WSL 终端）：

```bash
cd ~/projects/Aster-Ai/deploy/home
docker compose --profile quick ps     # relay / gateway / web 都应是 running
./verify.sh                           # 最后一行“全部通过”
```

任务没生效时看：`schtasks /Query /TN "知衡-保活-WSL" /FO LIST`，再手动运行一次任务。

### 2. 固定网址（可选，Cloudflare 命名隧道）

临时 `trycloudflare.com` 网址每次重连都会变；想让老师和学生用一个不变的网址：

1. 域名已托管在 Cloudflare。打开 Zero Trust → Networks → Tunnels，新建一条 cloudflared 隧道，复制 token。
2. 在这条隧道里加两个 Public Hostname：
   - 应用：`app.你的域名` → `http://web:8080`
   - 中继：`relay.你的域名` → `http://relay:8080`
3. 在 `deploy/home/.env` 里填 `APP_DOMAIN=app.你的域名`、`RELAY_DOMAIN=relay.你的域名`、`CF_TUNNEL_TOKEN=<token>`。
4. 在 WSL 里启动：`cd deploy/home && ./start.sh`。以后更新代码跑 `./update.sh`，网址不变。
5. `./verify.sh` 六项全过后，把固定网址发给老师和学生；临时隧道那套就可以不用了。

### 3. 更新代码后怎么更新环境（不要手工删 `data/` 里的文件）

```bash
cd ~/projects/Aster-Ai
git pull --ff-only
cd deploy/home
./update.sh
```

`update.sh` 会依次：备份成员名单与一次性口令 → 重新生成配置 → 按需重建并重启容器 → 核对名单人数与口令没变。
成员名单 `data/gateway/members.json` 被误删或清空时会先自动从 `data/backup/last/` 恢复，旧邀请不会因此失效。
更新后回归一次：`./verify.sh`；再用旧邀请链接打开一次，应该仍然能进。

### 4. 每一轮从头再来（清场）

每改完一版，内测都从建馆第 1 步重新走，不在上一轮的数据上接着试。部署电脑上一条命令：

```bash
cd ~/projects/Aster-Ai/deploy/home   # 按你放仓库的位置
./update.sh        # 先更新到最新代码并重建
./fresh-round.sh   # 清场：凭据与名单挪到备份、生成新口令、换一个新的老师浏览器
```

`fresh-round.sh` 会：

1. 把上一轮的老师登记凭据、核心成员凭据和成员名单**存在才移、不删**地移到 `data/backup/fresh-<时间>/`；
2. 跑 `update.sh`（它会等网页、网关、中继就绪后再验收），生成新口令；验收自测成员照旧补回名单；
3. 新建一个空的 Chrome 配置目录（`知衡内测-老师-<时间>`），把桌面快捷方式「知衡内测-老师Chrome」改成指向它，并用它直接打开**带这一轮一次性口令的登记链接**——电脑当老师时，建馆第 2 步的口令会自动填好；老师登记扫码页照旧生成，留给用手机当老师的情况；旧配置目录不删；
4. 不动中继数据、不重启 cloudflared，网址不变。

然后两台手机各点一次「设置 → 内测：清空这台设备 → 清空这台设备上的知衡」（见第五节第 5 步），回到第一次打开的样子；发起人从建馆第 1 步开始，按第六节逐项试。核心成员也随名单清掉了，要按第 14 项重新登记核心成员。

只想换老师、不清名单时，用 `./reset-teacher-setup.sh`（同样是存在才移、不删）。

## 四、老师这台设备（手机或电脑浏览器）

1. 打开网址 → 选「**我是老师**」→ 进入「建馆」引导（建馆 · 第 1 / 5 步）。走到哪一步关掉，再打开会从同一步接着走。
2. 第 1 步「接入自己的模型」：
   - 选 **DeepSeek / 千问 / 其他** 三个圆按钮里的一 个（用「其他」时再填接口地址和模型名称）；
   - 「模型账户密钥」填你的 API Key；
   - 点「**测试并继续**」→ 接通后会直接进入第 2 步。
3. 第 2 步「先登记您这位老师」：填「学生怎么称呼您」；「登记口令」不用手抄——
   在**部署电脑**上打开 `deploy/home/data/setup/teacher-setup.html`，用这部老师手机扫码，
   口令会自动填好；终端里也会打印同一个二维码。然后点「**登记，下一步**」。
   登记成功后，口令文件和扫码网页会被自动删掉（口令用过即作废）。
   手动粘贴老路也还在：`cat deploy/home/data/setup/teacher-setup-code.txt`，粘贴即可（前后空格/换行会自动去掉）。
4. 第 3 步「给您的馆起个名」：填「馆名」和「一句介绍」（与第 2 步的称呼一样必填），选「馆的颜色」→
   下面会立刻显示「学生看到的样子」→ 点「**就用这个名字**」。
5. 第 4 步「开馆」：下面列着六项开馆准备（模板、排班、邀约方式、药材库、保留期限、模型）。按顺序逐项看过并确认；可以修改默认值，或点「就这样，保存…」。药材库可选「不备药」。六项都确认后点「**开馆**」。这时门面正式生效。
   - 第 1 步的模型也可以「**先跳过，以后接模型**」。
   - 想让学生约面诊，「排班」要设；没设排班就不发面诊邀约。
   - 「邀约方式」里可以填「学生连续多少天不打卡，就请出名单」（14–365 天）；不填就不请出任何人。
6. 第 5 步「请第一位来面诊的学生当面扫码」：出现「邀请链接」和二维码，**1 小时内有效**。
   - 学生用另一部手机扫码或打开链接加入；学生进馆后老师端显示正在填写基础信息；资料填好后可点「开始面诊」。
   - 二维码下面可以「复制邀请」；长按二维码也能保存或分享。
   - 如果超过 1 小时，这里会写「邀请已过期」，点「**重新生成邀请**」换一张新链接。
   - 第一位学生迟迟没连上时，可以点「**先不面诊，进工作台**」直接进工作台；以后在「**我的馆** → 邀请学生」继续邀请。
7. 开馆后，第 2 位及以后的学生走「**我的馆**」→「**＋ 邀请学生**」→「生成邀请」（7 天内有效）。

## 五、学生这台设备（例如手机）

1. 打开老师发来的邀请链接 → 先看到邀请首屏（馆名/“老师邀请你”/开始使用）→ 点「**开始使用**」。
2. 看到「接入您的大模型」：同样选 Kimi、填自己的 API Key →「测试连接」→「✓ 连接成功」→「进入首页」。
   部署配了社区网关模型时，这一步最上面会有「**先用社区模型开始**」：点它就不用填 Key，以后想换再回来填。
3. 第一次进馆先看到「**进馆：先填基础信息**」：称呼、性别、出生日期、出生时辰（可选“实在不知道”）、出生地、居住城市、平时几点起和几点睡是必填；既往病史、在用药、过敏、西医诊断有就填。填完点「保存」才进首页。页面上写着：老师看不到具体日子和时辰，只看到年龄和健康八字。
4. 应进入学生首页（最上面是“天时与今日调养”，下面照镜子、今日作业），页首能看到“馆名 · 老师称呼”。
   底部三个标签：「**今天**」「**记录**」「**我**」；老师端是「**今天**」「**学生**」「**我的馆**」。
5. 每一轮内测开始前，先清空这台设备：底部「**我**」→「**设置**」→ 最下面「**内测：清空这台设备**」→「清空这台设备上的知衡」→ 输入「清空」→「确认清空」。会删掉这台设备上知衡的全部资料（身份、病历、照片、设置），删了找不回；清空后回到第一次打开的样子，再用这一轮的新邀请进来。老师端同理：「**我的馆**」→「**设置**」→ 最下面也是这个按钮。这个按钮只在内测部署里有，正式版本没有。

## 六、按顺序试这几件事

### 1. 照镜子、拍舌象（学生）

- 点哪里：学生「今天」→ 照镜子 →「拍今天的舌象」→ 允许相机/相册 → 拍一张舌头照片。
  （居住城市在「我」→「我的时间」里选，舌象区不再问；没选城市时按钮会提示先去选。）
- 应该看到：几秒后出现“舌头裁剪图 + 示意图 · 模型候选”，一行摘要（如“舌色… · 白苔、薄…”）；
  提示“原图已从应用内清除”。看不到“原图”。
- 也可以顺带点「我」→「这段时间自己感觉」里的一项；**只有这台手机看得到，老师看不到**。

### 2. 发问诊（学生）

- 点哪里：学生首页最下面「**不舒服？告诉某某老师**」→ 在「你的话」里说哪里不舒服（可以按键盘话筒）→「**说好了，继续**」。
- 应该看到：「再问一句」；不想回答就点「**跳过，直接整理**」，直到出现「问诊卡片」。
- 点哪里：看一眼卡片，需要改就点「**改一改你的话**」→「**发给某某老师**」。
- 应该看到：「已发给老师」。问诊三步顶端一直有一句「急症请立即去医院或拨打当地急救电话，别等老师回复。」；即使说到急症或自伤类的话，也只是这一句常驻提示，不弹窗、不显示电话号码，**发送按钮仍然可用**，不拦你。

### 3. 老师起草、签字（老师）

- 点哪里：老师「今天」→「等您签字」里点学生这一条。
- 应该看到：「某某 · 核对」：判断、方子、作业、医嘱一块一块；AI 草稿是虚线黄框，写着“草稿 · …”。
- 点哪里：逐块点「**就这样**」（有要改的点「改一改」）；草稿都确认完，“签字发出”才会亮。
  在“和上次比”里点一项（改善/持平/变差/说不准，**不点也能签**）→「**签字发出**」。
- 应该看到：「已签字交还」；页面上还有“这份草案像不像我？”评分，可点「跳过评分」。

### 3b. 老师当面看诊（老师）

- 点哪里：老师「**学生**」→ 点一位学生 → 页底「**＋ 开始面诊**」（「今天 → 开始面诊」也可以）→
  在“您说，智能体记”里用输入法的语音说一段（例如“舌淡红，苔薄白；入睡难；脉细弱”）→「**整理**」。
- 应该看到：望、闻、问、切四格自动填上；机器拆出来的格子是虚线并写“听到了，待您确认”，点格子可以改。
- 点哪里：说完了 →「**说完了，看草稿**」→ 逐块「就这样」→「签字发出」。
- 应该看到：「已签字交还」；学生的「记录」里能看到这份病历。

### 4. 学生收到病历和作业、打卡

- 点哪里：学生「**记录**」→「我的病历」；要展开看判断、处理、作业，点右上角「**全部 N 次**」。
- 应该看到：老师签字的那份病历（判断、处理、作业）。
- 点哪里：学生「**今天**」→ 今日作业右边圆圈点一下。
- 应该看到：圆圈变成对勾；今日作业右上出现“已连续 N 天”。

### 5. 老师说一句话记账、学生看余额（老师/学生）

- 老师点哪里：「**我的馆**」→「**看明细 ›**」→ 找到这位学生名字（还没记过账的会写“还没记过账”）→ 点「立即对账」→ 第一次记账先选「钱账币种」（默认是上次用过的），填「这位学生的称呼」和「说一句话记账」如“收到小王 100” →「生成记账草稿」→ 核对草稿 → 点确认（本人确认才入账）。
- 学生点哪里：「**我**」→ 点「在老师这里的余额」那张卡。
- 应该看到：老师第一次确认时自动建好这本账；学生这边是同一本账，余额显示老师记的金额与币种。

### 6. 老师改门面、学生看到新门面（老师/学生）

- 老师点哪里：「**我的馆**」→「**门面**」→ 改「馆名」和「颜色」→ 下方预览变化 →「**用这个样子**」。
- 应该看到：提示“已用这个样子…”。
- 学生点哪里：回学生「今天」页（或刷新一次）。
- 应该看到：页首门牌变成新馆名；再发问诊时仍发给同一位老师。

### 7. 清空学生浏览器、用换机链接认回（学生/老师）

- 老师点哪里：「**我的馆**」→「**设置**」→「**换手机**」→ 填你的称呼 →「生成“学生换手机”链接」→「复制」。
- 学生这台设备：先按浏览器“清除站点数据”（模拟换手机），再打开刚复制的链接。
- 应该看到：学生页「找回我的记录」→ 填“老师怎么称呼你”（例如“小王”）→「发给老师确认」。
- 老师点哪里：老师「**我的馆** → 设置 → 换手机」里出现「换手机认回」→ 选对应学生 → 点「**是**」。
- 应该看到：学生这边提示已认回；「记录」里保留期内的旧病历回来；钱账余额与换机前相同。

### 8. 加一位家人、代家人问诊（学生/老师）

- 学生点哪里：「**我**」→ 点「**家人**」旁的「管理 ›」→「添加家人」→ 填称呼、关系、出生日期、居住城市 →「添加家人」。
- 应该看到：家人出现在列表；「今天」页顶部可以切换“正在记录谁”。
- 点哪里：切到这位家人 →「不舒服？告诉老师」→ 同前面一样发一条问诊。
- 老师点哪里：「今天」→「等您签字」→ 打开这条问诊。
- 应该看到：卡片上写明是替哪位家人问诊（管理人与家人的代管关系）；签字交还后学生切到该家人能看到病历。

### 9. 问诊录音、两次整理（学生/老师）

- 学生点哪里：「不舒服？告诉老师」→ 在“你的话”下面「**按住录音**」，松开就停；可以录几段（每段不超过 3 分钟，一次合计不超过 10 分钟）。也照样打几句字。
- 应该看到：卡片页有「本次原话与问答」（逐句原话，带序号）和「本次录音」（能回放，可「删掉这段」）；追问的回答只在“追问记录”里，**不混进现病史**；卡片每栏下面写着“智能体整理 · 依据原话 #…”。
- 老师点哪里：「今天」→「等您签字」→ 打开这条。
- 应该看到：「学生智能体整理 · 学生已核对」「逐句原话」「追问问答」「原话录音」（能播放），以及「**老师智能体整理 · 待老师核对**」。签字发出后，录音和逐句原话从老师手机上删除（再打开这条问诊已经看不到）。
- 重点看：**iPhone 录的音老师那边能不能放**；粤语原话有没有被一字不改地保留。

### 10. 远程问诊带上家里的药材（学生/老师）

- 学生点哪里：问诊卡片页「**整理家里的药材 ›**」→ 记几味药和数量 → 回到卡片，「随问诊附上家里的药材」里能看到。
- 老师应该看到：开方时能看到这位学生家里有哪些药材、有多少；**库存不够也照样能签字**，只是有提示。

### 11. 预约面诊：同城与异地（老师/学生）

- 前提：老师在「我的馆 → 开馆准备 → 排班」里设好时段，同一页「老师所在城市」选好城市。
- 同城学生（居住城市和老师相同，或没填）：学生「今天」页有「**想预约？选几个方便的时间**」，选 1–3 个时间发出；老师按排班自动确认一个。老师「今天」页「请学生来面诊」里也能「一键邀约」，学生两小时不回就轮到下一位。
- 异地学生：学生「今天」页这里变成「**远程问诊**」；老师名单上标“异地 · 远程问诊”，不会收到面诊邀约。
- 改城市：学生在「我 → 我的时间」里把城市改成异地 → 老师名单上随之变成“异地”；如果已经约了面诊，学生端会问“这次面诊要保留吗？”，选「取消并通知老师」才取消。
- 老师当天：「今天的预约」里点「来了」或「没来」。

### 12. 学生智能体督促（学生）

- 前提：学生有一项到点没打卡的作业。
- 应该看到：到点 10 分钟后，「今天」页出现一句温和提醒；当天晚上还没打卡再提一次；第二天起每天一次，带上“这周作业 x/y，上周 x/y”。到了作息里写的睡觉时间，只提醒“先把手机放下”。
- 打一次卡，提醒就记为“已行动”，不再催这件事。

### 13. 请出名单与重新邀请（老师/学生）

- 老师在「邀约方式」里设「学生连续多少天不打卡，就请出名单」（最少 14 天）。
- 真等 14 天不现实，这一项先只看两件事：设置能保存；学生端提醒里出现“老师设的是 N 天不打卡就请出名单”这一类说法时，数字和老师设的一致。
- 到点后（以后再看）：学生端出现「与老师的智能体失联」；老师「今天」页「今天请出了谁」里有记录；老师重新发进馆邀请，学生就能回来，基础信息不用重填。

### 14. 成为核心成员、推荐一位老师（发起人）

- 部署电脑上跑完 `./update.sh`（或 `./setup.sh`），终端会打印“核心成员尚未登记”的二维码；也可以打开 `deploy/home/data/setup/core-member.html` 扫码。用过一次就作废。
- 用**您自己当学生的那部手机**扫就行：只登记为核心成员，手机仍是学生端，不会切成老师、不进建馆。应该看到提示“已登记为核心成员，现在可以推荐老师。”
- 推荐老师：学生端「我」→「设置」→「老师邀请」→ 写一句「为什么推荐这位老师」→「**推荐一位老师**」→ 出现链接和二维码（7 天有效，只能用一次）。
- 新老师（用另一部设备，或 iPhone 上的 Chrome）扫这个码：直接进入建馆，第 2 步不用口令；开馆后邀请一位学生进馆（可以就用您这部学生手机去接受）。
- 应该看到：新老师那边在学生进馆后自动进入「今天」；新老师设置里**没有**「推荐一位老师」。您在「老师邀请」里点「邀请已登记老师成为核心成员」，让新老师扫这张码 → 新老师设置里出现「推荐一位老师」，并提示“已成为核心成员”。
- 以前用部署口令登记过不止一位老师的：只有最近那位还算老师，其他人发的进馆邀请会被拒；用推荐链接给他们重新登记一次即可。
- 不要用无痕 / 隐私窗口扮演角色：窗口一关，那个身份就没了。

## 七、装到手机主屏幕（老师和学生都做一次）

- iPhone / Safari：点底部分享按钮 →「添加到主屏幕」→ 名称用「知衡」→ 添加。以后从主屏幕图标打开，就像 App 一样。
- Android / Chrome：点右上角三个点 →「安装应用」或「添加到主屏幕」。找不到时先刷新一次页面。
- 老师端和学生端用的是同一个应用，两边都可以添加；加完打开仍是同一个网址的数据。
- 添加后如果更新了应用，重新打开一次即可；页面本身不缓存业务数据。
