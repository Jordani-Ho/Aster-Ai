# 内测怎么开始

给发起人本人看的一页说明。每一步都写清“点哪里、应该看到什么”。
遇到问题就记在 `team/selftest-notes.md`（一条一行：日期、做了什么、看到什么、期望什么）。

## 一、准备

- 电脑（Windows）开着，WSL 里的部署起起来；准备两台设备：**电脑当老师**、**手机当学生**（反过来也行）。
- 两台设备打开的是**同一个网址**。
- 各自有一个能用的模型钥匙（例如 Kimi 的 API Key）；没有的话先按提示接入，模型只用来整理文字/看图，不替老师签字。

## 二、在家里电脑上启动

1. 打开 WSL（Ubuntu）终端，进入仓库目录：
   `cd ~/projects/Aster-Ai/deploy/home`（具体路径按你放仓库的位置）。
2. 启动：`./quick-start.sh`
   - 第一次会构建镜像，等 10–30 分钟；以后大约 1–3 分钟。
   - **最后一行**是一个 `https://…trycloudflare.com` 网址，这就是手机要打开的地址。
3. 停止：在同一个目录执行 `docker compose --profile quick down`（数据还在 `data/`，不会删）。
4. 重新开始：再跑一次 `./quick-start.sh`。临时网址每次会变，以最后一行打印的为准。

## 三、老师这台设备（例如电脑浏览器）

1. 打开网址 → 选「**我是老师**」。
2. 看到「接入您的大模型」：
   - 「选择服务商」选 **Kimi（月之暗面）**；
   - 「接入凭证」填你的 Kimi API Key（接口地址和模型名称已自动填好，不用改）；
   - 点「测试连接」→ 应看到「✓ 连接成功」；
   - 点「进入首页」→ 应看到老师首页「今天」。
3. 第一次建社区：进「**管理**」→ 展开「我是这个社区的老师」→ 填部署口令 → 点「登记为社区老师」。
   口令在电脑上：`cat deploy/home/data/teacher-setup-code.txt`。
   应看到「社区已建立，可以邀请学生」。
4. 点「**邀请学生**」→ 出现「邀请链接」和一个二维码；下一步给手机用。

## 四、学生这台设备（例如手机）

1. 打开老师发来的邀请链接 → 先看到邀请首屏（馆名/“老师邀请你”/开始使用）→ 点「**开始使用**」。
2. 看到「接入您的大模型」：同样选 Kimi、填自己的 API Key →「测试连接」→「✓ 连接成功」→「进入首页」。
3. 应进入学生首页「**镜子**」，页首能看到“馆名 · 老师称呼”。

## 五、按顺序试这几件事

### 1. 照镜子、拍舌象（学生）

- 点哪里：镜子页 →「拍舌象 / 重拍」→ 第一次先选「居住城市」→ 允许相机/相册 → 拍一张舌头照片。
- 应该看到：几秒后出现“舌头裁剪图 + 示意图 · 模型候选”，一行摘要（如“舌色… · 白苔、薄…”）；
  提示“原图已从应用内清除”。看不到“原图”。
- 也可以顺带点“这段时间自己感觉”里的一项；**只有这台手机看得到，老师看不到**。

### 2. 发问诊（学生）

- 点哪里：底部「问诊」→ 在输入框里说哪里不舒服（可以按键盘话筒）→「发送」。
- 应该看到：追问气泡，可点「跳过」；整理出「整理好的卡片」。
- 点哪里：核对/修改卡片 →「**发给老师**」。
- 应该看到：「已发给老师」。

### 3. 老师起草、签字（老师）

- 点哪里：「远程」→ 看到学生这条问诊 →「打开问诊」。
- 应该看到：「病历草稿」整张卡片（学生陈述、判断、处理、作业）。
- 点哪里：先看一遍；在“和上次比”里点一项（改善/持平/变差/说不准，**不点也能签**）→「**签字发出**」。
- 应该看到：「已签字交还」；页面上还有“这份草案像不像我？”评分，可点「跳过评分」。

### 4. 学生收到病历和作业、打卡

- 点哪里：学生「其他」→「我的病历」。
- 应该看到：老师签字的那份病历（判断、处理、作业）。
- 点哪里：「其他」→「今日作业」→ 到点的作业旁点「打卡」。
- 应该看到：按钮变成「今日已完成 ✓」；镜子页页首出现“已连续练习 1 天”。

### 5. 老师说一句话记账、学生看余额（老师/学生）

- 老师点哪里：「管理」→ 展开「钱账与对账」→ 找到这位学生名字（还没记过账的会写“还没记过账”）→ 第一次记账先选「钱账币种」（默认是上次用过的），填「这位学生的称呼」和「说一句话记账」如“收到小王 100” →「生成记账草稿」→ 核对草稿 → 点确认（本人确认才入账）。
- 学生点哪里：「其他」→ 展开「设置」→「钱账与对账」。
- 应该看到：老师第一次确认时自动建好这本账；学生这边是同一本账，余额显示老师记的金额与币种。

### 6. 老师改门面、学生看到新门面（老师/学生）

- 老师点哪里：「管理」→「我的门面」→ 改「馆名」和「颜色」→ 下方预览变化 →「**用这个样子**」。
- 应该看到：提示“已用这个样子…”。
- 学生点哪里：回镜子页（或刷新一次）。
- 应该看到：页首门牌变成新馆名；再发问诊时仍发给同一位老师。

### 7. 清空学生浏览器、用换机链接认回（学生/老师）

- 老师点哪里：「管理」→「换手机找回」→ 填你的称呼 →「生成“学生换手机”链接」→「复制」。
- 学生这台设备：先按浏览器“清除站点数据”（模拟换手机），再打开刚复制的链接。
- 应该看到：学生页「找回我的记录」→ 填“老师怎么称呼你”（例如“小王”）→「发给老师确认」。
- 老师点哪里：老师「今天」页出现「换手机认回」→ 选对应学生 → 点「**是**」。
- 应该看到：学生这边提示已认回；「我的病历」里保留期内的旧病历回来；钱账余额与换机前相同。

### 8. 加一位家人、代家人问诊（学生/老师）

- 学生点哪里：「其他」→「添加家人」→ 填称呼、关系、出生日期、居住城市 →「添加家人」。
- 应该看到：家人出现在列表；镜子页/问诊页顶部可以切换“正在记录谁”。
- 点哪里：切到这位家人 →「问诊」→ 同前面一样发一条问诊。
- 老师点哪里：「远程」→ 打开这条问诊。
- 应该看到：卡片上写明是替哪位家人问诊（管理人与家人的代管关系）；签字交还后学生切到该家人能看到病历。

## 六、遇到问题

- 记在 `team/selftest-notes.md`：一条一行，写清**日期、做了什么、看到什么、期望什么**。
- 同时截图（手机/电脑都行），文件名写进那一行，方便以后对照。
