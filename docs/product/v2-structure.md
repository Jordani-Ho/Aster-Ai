# 第二版结构图（草案 v0.2，2026-10-18）

依据：`docs/product/two-agents.md`、`docs/product/handoff-relations.md`、`team/decisions.md`（2026-10-17、10-18 各条）。只讲模块和关系，不讲代码。

## 〇、三层：我们管宏观，智能体管微观（发起人 2026-10-18）

| 层 | 谁负责 | 内容 |
| :-- | :-- | :-- |
| **底层** | 我们 | 天时、抽象器、传递、两本账、观察；所有“元素”（界面零件、作业类型、提醒方式……） |
| **智能体架构** | 我们 | 老师智能体、学生智能体怎么组成、怎么学习、能改什么 |
| **表层** | 每个智能体自己 | 界面长什么样、叫什么名字、怎么说话、模板、提醒、参数——老师或学生有需要（哪怕说不清，只是感觉不对），由自己的智能体去调，不由我们统一调 |

- **门面属于老师**：A 老师的学生看到的是“阿慈养生馆”，B 老师的学生看到的是“小黄运动馆”；不是一个统一的大平台。用的人知道这个社区，不用的人不需要知道。
- **智能体改的是“配置”，不是代码**：界面、话术、模板都由数据描述，智能体修改这些数据；我们只维护零件和规矩。
- **智能体改不了的**：三条底线（急症提醒、签字只能老师本人、他人不能冒充老师），以及康币的社区规则——这些属于宏观结构，由我们调整。

## 一、地基：每一条记录都带“天地人”

| 字段 | 含义 | 粒度 |
| :-- | :-- | :-- |
| 天（时） | 时辰（按当地太阳时）+ 节气（天文时刻换算到当地日期） | 时辰，不到分秒 |
| 地 | 所在城市（用于天气和真太阳时） | 城市 |
| 人 | 本人或某位家人 | 人 |

## 二、十四个模块（每块只做一件事）

| # | 模块 | 只做什么 | 第一版里可复用的 |
| :-- | :-- | :-- | :-- |
| 1 | **人** | 本人与家人是谁；界面上没有密钥 | 身份、家人账户（去掉助记词界面） |
| 2 | **天时** | 时辰、节气、天气 | 八字/真太阳时、节气、天气 |
| 3 | **抽象器** | 照片 → 抽象图 + 几项特征，原图立即删除 | 照片压缩（改为抽象） |
| 4 | **镜子** | 每天固定时辰照一次：抽象舌象、状态、压力；当日建议 | 镜子页、走势、每日建议 |
| 5 | **问诊** | 对话 → 一张卡片 → 发给老师 | 对话式问诊、追问 |
| 6 | **方案** | 老师给的体质与调养方案、作业（时辰/节气/随习惯）、练习视频 | 调养方案、作业排程、随习惯 |
| 7 | **坚持与效果** | 坚持了多少（时间）× 变好了多少（效果，只和自己比） | 坚持率计算 |
| 8 | **康币账（虚）** | 记康币的来与去；规则是一张可调的表 | 第一版账本的“链”与签名可复用，改记康币 |
| 9 | **钱账（实）** | 充值、赠送、扣费；老师一句话记账 | 第一版康币账本（改名为钱账） |
| 10 | **老师智能体** | 起草、改稿、记账、沉淀思想指纹；签字只能老师本人按 | 起草、改稿、一键签字 |
| 11 | **传递** | 把东西从一部手机送到另一部；只传抽象过的内容 | 中继与消息（可大幅简化） |
| 12 | **观察** | 让发起人和老师看见社区在发生什么，为调规则提供依据 | 试点指标导出 |
| 13 | **自我调整** | 智能体按老师/学生的需要（或观察到的问题）修改自己的界面、话术、模板、提醒等配置 | 调养方案与改稿的“说一句话改”模式 |
| 14 | **门面** | 老师自己的馆名、标志、颜色、链接；学生看到的是老师的馆 | 邀请链接 |

另有两条横穿所有模块的规矩：**急症只提醒、不拦截、不给电话（自伤类除外）**；**保留期限由老师定，师生互为备份**。

## 三、关系：谁把什么交给谁

| 从 | 到 | 交出什么 | 关系 |
| :-- | :-- | :-- | :-- |
| 天时 | 镜子、方案 | 今天的时辰、节气、天气 | 人与自然 |
| 抽象器 | 镜子、问诊 | 抽象图与特征（不是照片） | 人与自我 |
| 镜子 | 坚持与效果 | 每天同一时辰的记录 | 人与自我 |
| 问诊 | 老师智能体 | 一张问诊卡片 | 教学 |
| 老师智能体 | 方案 | 老师签字的方案与作业 | 教学 |
| 方案 | 镜子 | 今天该做什么、提醒什么 | 教学 |
| 坚持与效果 | 康币账 | 时间 × 效果 | 价值 |
| 问诊/面诊 | 康币账 | 占用老师几刻 | 价值 |
| 老师（说一句话） | 钱账 | 收了多少、送了多少、扣了多少 | 交易 |
| 各模块 | 观察 | 只给汇总，不给个人内容 | 运营 |
| 老师/学生（说出或感觉到的需要） | 自我调整 | 想怎么改 | 人与自己的智能体 |
| 自我调整 | 表层配置 | 改后的界面、话术、模板 | 智能体与自身 |
| 观察 | 我们 | 宏观结构要调什么 | 社区运营 |

## 四、第一版里可以整个拿掉的

端到端加密（礼物包裹）、本地存储加密、助记词与恢复界面、中继加密备份、刷脸/通行密钥保护、“诊毕即还”的多步销毁流程、照片去 EXIF 流水线（改为抽象后直接删原图）。

## 五、还没定、留给运营观察的

康币的具体比例、效果三方（老师判断、本人感受、实测）各占多少、变差扣多少、“贵族”有什么不同、社区总值是否公开、与法币/比特币的连接。地基里都留好位置（可调规则表 + 观察模块），不写死。
