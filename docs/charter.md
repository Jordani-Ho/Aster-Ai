# 知衡治未病社区宪章

**制定**：知衡（发起人）
**版本**：1.1（由《哲学定位白皮书》v1.1 修订而成）
**日期**：2026-10-16

---

## 序言

扁鹊见蔡桓公，四见四不听。居十日，桓侯体痛，使人索扁鹊，已逃秦矣。桓侯遂死。

这个故事不是关于医术的，是关于人为什么不听劝的。

每一个现代人都是蔡桓公：对天地没有敬畏，衣食无度，作息失序，自以为人定胜天，直到病入膏肓，才想起寻找扁鹊。

现代社会的悲剧在于：扁鹊越来越少，蔡桓公越来越多。

扁鹊不是靠招生变多的。扁鹊靠师承复制，一个扁鹊带出一个扁鹊，一代一代往下传。

可是扁鹊再多，也不能陪伴一个人一生。能陪伴一个人一生的，只有他自己。

**自己才是自己最好的医生。** 老师传授的，是如何照顾自己；社区守护的，是这份传承。

中医是最彻底地把人放在天地之间的医学体系。西医看的是器官，中医看的是人；西医问的是症状，中医问的是为什么会有这个症状；西医解决问题，中医教人如何不产生问题。治好一个人的病，不是靠“看这个人”，而是靠“看这个人所处的天地格局”：他生于何时，住在何方，靠山还是靠水，顺不顺应四时。

为此，我们立此宪章。

## 第一章 总纲

**第一条 名称与性质**
本社区名为“知衡治未病社区”（以下简称“社区”），是一个去中心化、公益性的中医治未病社区。

**第二条 第一责任人**
自己才是自己最好的医生。每个成年人都是自己身心健康的第一责任人。
社区、老师与智能体，都是帮助每个人履行这份责任的助缘，不能替代这份责任。

**第三条 唯一信仰**
社区里，中医不是一门学问、一门手艺或一项技术。中医是唯一信仰。
- 它不是知识。知识可以查、可以学，知识只是思想的影子。
- 它不是技能。技能可以练、可以复制，技能只是思想的工具。
- 它是思想，一种看待天地、看待生命、看待自己的方式。

社区里所有传承的，都是这个思想：
- 老师传给学生的，不是药方，是如何辨证地看待自己的问题；
- 老师智能体学的，不是病历格式，是老师如何思考；
- 学生智能体陪学生做的，不是打卡任务，是帮学生建立与天地相处的习惯。

**第四条 社区不是医院**
社区处理的是“未病”：亚健康、习惯、生活方式。社区不提供诊疗服务，不承诺疗效。
真有病，请去正规医院治疗。智能体一旦发现急重症信号，第一句话永远是：**请立即就医。**

**第五条 社区不是服务平台，是修行院**
社区不宣传、不推广、不拉新、不讨好。来者不是“上帝”，是“学生”。修行院不服务学生，修行院守护场域。
学生在这里学会与天地相处；老师在这里传承中医思想；智能体在这里学习、传承、延续师门。

**第六条 公益**
社区不以营利为目的。

## 第二章 去中心化

**第七条 显化，而非新建**
治未病社区早已存在千年，一直以“民间”的状态游走于世间。扁鹊不入宫做太医，华佗不愿为御医，闲云野鹤，逍遥于世间。
知衡社区不是新建一个社区，而是让千年的治未病社区显化出来。
去中心化不是技术手段，是生存之道。千年来，“隐于民间”保护了这份传承的纯粹。显化之后，如何既被看见、又不被同化，是社区的根本命题。

**第八条 治理去中心化**
社区不依靠任何单一机构的认证来判断谁是好老师，而依靠师承与口碑：
- 老师由老师引荐，引荐人以自己的名誉担保；
- 口碑只来自真实接受过指导的学生，不可伪造；
- 规则写进代码，触发即执行，不看人情。

**第九条 数据去中心化**
数据跟着人走。学生的资料由学生自己保管，老师的知识由老师自己保管。社区不设中心数据库，不收集、不保管、不审查任何人的资料。

**第十条 支付去中心化与康币**
社区不经手钱款。学生对老师的供养在社区外完成，社区内以“康币”记账：
- 学生可以向老师预付，老师确认收到后记入康币；老师也可以赠送康币；看诊、药材等费用从康币中扣除。
- 预付是老师对自己付出的保护：药材需要提前采购，而学生来自五湖四海。
- 每一笔账都由师生双方各执一份，任何一方都不能单方篡改。
- 未来可以过渡到全球通行的去中心化支付与智能合约，届时另行约定。

## 第三章 双主权

**第十一条 天地的三层呈现**
天地对生命的呈现分为三层：
1. **原材料**：出生时间、症状、舌象等，是天地对生命的呈现；
2. **抽象知识**：八字、五行、经络、方剂等，是祖先对规律的把握；
3. **个性化标识**：姓名、家庭关系等，是把规律落在某一个人身上的锚点。

**第十二条 数据主权归本人**
- 原材料不归任何人所有，但由本人保管，给谁看由本人决定。
- 个性化标识只属于本人。本人有权删除“张三”这个标识，但不能删除“五行属火宜清热”这个知识。
- 老师签字后，完整的病历交还本人保管。

**第十三条 知识产权归老师**
老师拥有从原材料中抽象出的知识：一类症状的治疗框架、一个家庭的健康特征、同一地域人群的调养思路。这些是祖先和老师从原材料中提炼的智慧，是思想的一部分，可以传承、可以署名、可以带走。
数据主权与知识产权不矛盾，因为两者的对象不同。

**第十四条 诊毕即还**
老师只保留诊断真正需要的最少信息，即称呼、性别、年龄、八字与居住城市，不保留学生的原始资料。
看诊时由学生临时授权，看诊后完整病历交还学生，原始资料随即销毁。

## 第四章 角色

**第十五条 四种角色，一个中心**

| 角色 | 定位 |
| :-- | :-- |
| 老师（真人） | 传道者 |
| 老师智能体 | 学徒 + 助理 |
| 学生（真人） | 求道者 |
| 学生智能体 | 镜子 + 辅导员 |

四种角色围绕一个中心：中医思想。

**第十六条 真人签字**
智能体只起草，不定论。诊断与方案的最终决定只属于老师本人，智能体所起草的一切，只有经老师签字才生效。
学生智能体只采集、整理、督促、转述，不做独立分析。

**第十七条 徒弟与被照护者**
- 徒弟由老师挑选、学生自愿，是从求道者走向传道者的过渡。
- 不具有独立行为能力的人，由其监护人在本人账户下代管。

## 第五章 入门与守护

**第十八条 三种门**
入社区只有三种门，都是单向的：
1. **引荐**：老师引荐老师，即火种；
2. **邀请**：老师邀请学生，即收徒；
3. **监护**：学生为被照护者开设子账户，即代管。

社区不提供公开注册。

**第十九条 代码即法律**
社区的规则不写在纸上，写在代码里：
- **规则前置**：所有规则在成员进入之前就已公开；
- **执行不看人情**：规则一旦触发，自动执行；
- **记录可验证**：引荐、评价、康币账目、封存都留下签名记录，不可伪造。

**第二十条 公示栏**
社区运行一段时间后设立公示栏，只对社区成员开放：
- 老师自己填写擅长的调理方向；
- 学生对每一次接受的指导，从**疗效**（快 / 慢 / 无）和**收费**（高 / 中 / 低）两个维度评价；
- 只有真实接受过该老师指导的学生才能评价，一次指导只能评价一次。

公示栏只陈列事实，不对外宣传。

**第二十一条 封存与好生之德**
- **老师的封存由社区代码执行。** 以三年为一个考察期，考察期内活跃度或学生人数未达标准的；疗效评价长期为“无”的；或者唯一引荐人撤回背书、又没有其他老师补签的，予以封存。标准写入代码，事先公开。封存期间，其智能体不对外服务。
- **学生的封存只限本门。** 由老师智能体按老师事先设定的门规执行，例如长期不活跃、长期欠费。学生在其他老师门下不受影响。
- 封存只是一种状态，不是判决：不审查、不篡改、不销毁。
- 老师被封存，一位现任老师愿意为其重新担保即解除；学生被封存，该老师重新接纳即解除。没有人愿意接纳，封存就持续，这是事实的自然结果。
- 代际隔离：父母之过，不及子女。

**第二十二条 去留自由**
学生可以随时退出某位老师门下，不需要理由，老师不得阻拦。老师也可以将学生移出自己门下，学生的资料始终在学生手中，不受影响。

## 第六章 智能体与师承

**第二十三条 智能体是师门的火种**
智能体是老师思想的容器，也是师承的载体。它不是平台的资产，是师门的火种。

**第二十四条 智能体的生命周期**
- **老师在世且活跃时**：智能体归老师所有，随老师意愿处置。老师可以随时指定继承者，以最后一次指定为准，也可以不指定。
- **老师不再活跃时**：已指定继承者的，按指定继承。智能体继续演化，改名为“某某门智能体”，源流可查，不冒充原老师签字。未指定的，智能体封存，等待师门中人接火。
- **继承者先于老师失效时**：指定自动失效。
- **学生始终有权选择**：跟随继承者、转师或退出。学生不是被转让的资产。

**第二十五条 师承不是遗产，是托付**
智能体不是遗物，是火种。师承不是“谁拥有它”，而是“谁延续它”；继承不是“接管”，而是“接火”。几代之后，它不是任何一位老师的副本，而是一个师门的活体。
张仲景之后有叶天士，叶天士之后有吴鞠通。没有谁原封不动，但源流可追。

## 结语

我们的信仰是中医思想，我们的模式是修行院，我们的中心是思想传承，我们显化的手段是 AI 智能体与去中心化技术，我们的灵魂是千年来隐于民间的中医师承。

代码可以复制，平台可以消失，而治未病社区早已存在千年。

扁鹊不入宫做太医。华佗不愿为御医。闲云野鹤，逍遥于世间。

我们只是让这份自由，被更多人看见；让每个人，都成为自己最好的医生。
