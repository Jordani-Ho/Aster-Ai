# V2-04 钱账与康币账格式（B 类，交 Claude 审核）

钱账复用 `core/ledger` 的老师签名链、学生异议、对账与持久出站队列。事件 kind 2729、ledger 师生绑定与链 prev 不变，content 新增必填 `currency`（ISO 货币代码）；amount 是该货币最小单位的正整数。例：CNY 100 元写 10000，JPY 100 日元写 100，KWD 1.234 写 1234；不做货币间换算。

事件 `topup/gift/charge/refund` 分别为充值、赠送钱、扣费、退款。余额为前两项减后两项，允许欠费；退款沿用累计充值减累计退款的限制，赠送钱不增加可退现金额度，不重新定义退款政策。同一本账首次记账后固定币种，混币种、金额/累计金额溢出均拒绝。

可选 `confirmationId` 是真人确认一份草稿的幂等编号。一次口述可以包含多笔事件；recordBatch 先验全批次、签名后将链与待发队列一次写入同一 IndexedDB 记录。重复确认返回原事件，改内容复用同编号拒绝。签字病历扣费使用该签名事件 id 去重。

一家一本钱账（代管人与老师之间），`forMember` 为可选家人称呼，所有事件均可标注；家人问诊扣费仍核对代管证明。金额、币种、对象及家人均在确认卡上展示，模型不签名、不确认、不转账。模型只接收老师原话、所选学生称呼、所选币种及允许的家人称呼，不接收身份私钥。

`money-drafts` 保存待恢复原话或待确认草稿，跨恢复沿用同一个确认 id。模型失败后重载、联网或回到页面只重做草稿；确认必须老师再点。修改/取消会删除旧草稿，成功入账后删除草稿。钱在社区外走，系统没有支付接口。

康币单独使用 `domain/tcm/kangbi-rules.json`，数值全部 null；只有纯计算函数、事件类型、个人观察记录与匿名汇总接口。生产不自动产生/扣减，不显示余额；测试专用规则覆盖时间×效果、零效果、下降、流向与日上限。无钱账与康币账的换算函数，无外部货币连接实现。

第二版没有真实旧用户，不做迁移、不支持第一版“康币=价钱”的数据格式。完整身份、公私钥、账目仅在各人本机与本人参与的师生同步中使用；观察接口不返回个人明细。多标签/多设备同时写同一老师账仍不支持，沿用现有冲突检测。
