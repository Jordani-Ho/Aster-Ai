## 1. 定什么，不定什么

康币衡量健康价值，单位是“刻”（15 分钟），不表示价格，不从钱账折算。要分清三种变化：坚持且有效创造价值；占用老师时间发生师生间流转；健康变差可能发生减少。流转不增加社区总量，减少不应伪装成转给老师的收入。

观察能告诉我们评分是否稳定、改善需要多久、典型问诊用了多少时间、某种规则会产生怎样的分布。**观察不能唯一推出“一个人的改善值几刻”或“变差应扣多少”**：这些仍是发起人的价值选择。15 分钟是已有单位定义；一天健康改善等于多少老师时间，不是从照片或打卡次数里自然长出的常数。

本方案提出收集、比较和拍板的方法；所有候选数值都先留在试算材料中，不写进生产规则表。接受本方案不等于接受某套权重、扣减或启用规则。

## 2. 内测观察什么

### 先统一“同一件事”的口径

基本观察单位是“同一人相对自己的一个完整观察周期”，有起点、终点和期间坚持情况。周期长度按调养目标的反馈速度事先约定，不把每天照片都当一次独立改善。更换目标、量表、模型或测量条件后分段看，不把前后分数直接拼起来。

先把变化描述成“改善／持平／变差／不确定”，三方分别填，彼此不先看分数；具体等级如何映射为可相加的数值，另列为待发起人确认的量表。没有共同量表就不平均，不能把压力自评、舌色类别和模型置信度直接相加。

| 要观察的内容 | 为了回答什么 | 怎样避免误读 |
| :-- | :-- | :-- |
| 实际参与人数、老师数、完整周期数、退出与失访数 | 样本是否被少数活跃师生包办 | 人数、师生对、周期分别报；一个人连续打卡不变成许多独立的人 |
| 周期内有效坚持天数、未记录与中断 | 有效改善伴随怎样的坚持 | 打卡天数是坚持线索，不等于真实练习时长；缺记录不是零努力 |
| 老师判断、本人感受、实测变化，各自是否缺失 | 三方看到的是否是同一个变化 | null 是未评价，不是持平；三方评价同一周期，不用错开的时间点凑齐 |
| 与本人基线的变化、重复测量的波动、随后周期是否维持 | 变化能否区别于日常噪声 | 不与其他人的绝对健康水平排队，不把光线、模型换版造成的变化算改善 |
| 老师真实投入时间、问诊类型、问诊次数 | 时间流转和按次后备值如何估计 | 设备打开到签字只是经过时间，含挂机、切后台，不能直接视为有效工时 |
| 三方分歧、反复改分、重复提交、极端值与集中度 | 哪些规则容易失真或被利用 | 异常是复核线索，不是作弊结论；老师正常风格差异也要看见 |

只为同一目标保留少量有解释力的指标。实测可以来自已有、可重复的个人趋势，但“实测”不等于真相：模型读同一份自述仍可能与自评分同源，舌象颜色也有光线误差。记录测量方式与版本的口径，先在当地现有资料可用期间核对，不为定值延长照片或病历保留。

### 现有记录够做什么，还缺什么

现有 `kangbi-observations` 有练习天数、老师分钟数、问诊次数及三方评分；缺评分留 null。当前采集中的老师分钟来自打开到签字的设备计时，三方评分尚未完整采集。不能把接口支持一个字段当成已经获得可信数据。

现有 `kangbiSummary` 的人数包含老师和学生，不能直接当学生样本数；计数和评分合计也不能还原三方配对、方差、缺失组合、周期变化或异常集中度。仅靠现在的汇总，**不足以校准三方权重与防串通效果**。

建议后续观察模块在各自设备上形成周期配对、分布、缺失率和试算结果，再只给运营端汇总。哪些来源已确认、哪些时间只是经过时间、哪些量表版本可比较，也应能在本地核对。它们是后续需要 Claude 拆卡的能力，本方案不新增字段或导出个人流水。

运营摘要不出现姓名、公钥、照片、病历或可逐人拼接的轨迹；跨设备重复观察先按已有事件归属在本地对齐，不能把老师和学生各存一份算两份。尚不能可靠去重时，摘要写“设备覆盖数／人数未核实”，不用相加假装社区总人数。小分组可能认出人时合并展示，不为了统计再造中心个人数据库。

## 3. 攒多少才够：计划规模与放行条件分开

可把首轮排期草案设为 **6–8 周、20–30 位学生、2–3 位老师**，用于估计缺失、重复性和工作量；这是招募与观察计划建议，**不是康币规则，也不是保证“够了”的门槛**。只有一两位老师时照常观察，但结论只适用于这些场景，不宣称已经验证全社区。

最后要多少人，由第一轮实际波动和愿意承受的误差决定。先约定“统计误差多大就会改变这次拍板”，再按波动估计所需独立样本。估计均值时可用 `n ≈ (z × s / ε)²` 做粗排期：s 是首轮估得的波动，ε 是可接受误差；小样本再用适合的区间核算。精度与波动决定所需样本量，而不是一律收固定条数。方法依据见 [NIST：样本量与精度](https://itl.nist.gov/div898/handbook/ppc/section3/ppc333.htm)及[均值置信区间](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm)。

纯演算例：若某个已约定量表上的 s 为 0.8、希望误差约为 0.25，用 95% 区间近似得到约 40 个独立单位。它只解释如何估样本，不是给社区定分数、不是权重样本量保证，也不能用同一人 40 天代替 40 个独立单位。共享老师的学生也相关；分析时按人、按老师分组看，老师太少不能靠公式补足代表性。

准备第一次拍板前，逐项回答：

1. **能测了吗？** 三方口径一致，重复测量噪声可见；不是多数评分仍为 null，也不是把缺失当零。
2. **覆盖了吗？** 有改善、持平、变差与中断情况，有不同老师和本人／家人场景；某类没有就明确该项暂不能定，不为了凑数诱导健康变差。
3. **稳了吗？** 前后观察批次、留出后续周期、去掉任一老师或高活跃者后，候选方案的主要结论不翻转；报告范围与不确定性，不只给总平均。
4. **能区分候选了吗？** 数据误差已小到足以区分这次要比较的方案；区分不了，就保留多种选择，不输出虚假的唯一最优值。
5. **扛过试刷了吗？** 高分全满、重复天数、挂机问诊、串通师生和多账户的模拟结果已摆上摘要，没有未说明的无限增发入口。

每次复盘显示“已有多少／还缺哪类／下轮补什么”，不要只显示倒计时。未达条件就继续观察，生产仍全 null。即使达到条件，也只能请发起人决定是否进行有边界的首次启用，不自动放行。

## 4. 怎样从观察走到候选数值

先固定观察窗口、量表和判别口径，划分早期探索与后续留出周期。探索数据用来提出候选，后续数据用于检查，不在同一批数据上反复调到最好再报成功。不得以“发得最多”“人人余额上升”或“老师最满意”为优化目标。

| 待定项目 | 从观察得到的依据与候选生成方法 | 发起人仍需决定什么 |
| :-- | :-- | :-- |
| 三方权重 | 在可比量表上，分别看重复性、缺失、方向分歧、与随后持续变化的一致程度；考虑同源相关。围绕更均衡、偏稳定证据等思路做少量候选，对单方虚高、双人串通逐一试算 | 三方各占多少；来源缺失或分歧时是否暂缓，不让程序自行重分配权重 |
| 每天折几刻 | 先选“已证实改善、坚持口径清楚”的参考周期，展示各周期有效天数与效果。请发起人判断这种参考改善值得多少刻，再把该目标量反推到每天系数，检查其他周期分布 | 参考改善的价值锚；不是按问诊收费或补贴预算换算 |
| 变差扣多少 | 先看持平波动下会误判多少次、持续变差与偶发波动如何区分；模拟不同扣减强度下的误扣、负余额与负担分布 | 何种变差纳入、扣减强度、是否允许负余额及保护情形；证据不足可继续不启用该规则 |
| 问诊几刻 | 已有单位以有效投入分钟对应刻；用核实后的时间分布，比较不同问诊类型的典型值与长尾。按次系数只作为有效时间缺失时的候选后备，用同类型时间分布估计 | 是否准许按次后备、怎样分型与处理异常；一次问诊不能同时按时长和按次重复扣 |
| 每日上限 | 在不设上限的影子试算中看正常可核实活动的分布，再注入极端记录；对照候选上限下正常受限比例、异常能多拿多少、最高集中度 | 对正常活动误限与对刷量限制之间的取舍；上限不能成为每天必发的定额 |

量表必须先让“零”确实表示无可辨改善，而不是缺资料。权重可比较一致性，但三方投票多数并不是真值；老师不能既做唯一正确答案又因与自己一致而得到最高权重，模型也不能因重复学生的话而被当成独立证据。尚无独立后续依据时，只报一致与分歧，不能声称学到了最准确权重。

单位“刻＝15 分钟”已由发起人给定；`minutesPerKe` 的生产值仍保持 null，等同批启用裁决。健康创造系数不是“所有练习时间除以 15”，问诊流转也不是再新造一份康币。所有时间先去掉明显非投入部分，不能让等待签字越久收益越高。

每天系数的反推可用符号说明：参考周期有 D 个有效坚持日、加权效果为 E，发起人为这段参考改善选择目标价值 K，则候选日系数为 `K / (D × E)`；仅适用于 E 为正、口径已定且资料完整的周期。对多个参考周期看分布与偏离，不挑一个最好案例代表所有人。K、各权重、上限等均不在本文赋值。

**一个周期的改善只结算一次。** 若效果来自周期起止差，不得把同一个改善幅度天天复用；影子试算需说明怎样分配到周期内有效日、怎样累计并逐日应用上限。减退幅度也不能每次打开页面重复扣。效果为零不创造；不确定不当零；已用于创造的变化不能换个周期再次申领。

现有计算器只提供数值计算，不解决量表、归因、周期结算、证据与复核规则；当前还是有一项生产规则或三方评价为 null 就不计算。方法若需要“先启用部分、其他继续观察”，必须另行拍板与拆卡，不能直接把空值填零绕过停用条件。

## 6. 防刷：减少收益入口，不把三方评分当防伪证明

| 风险 | 建议先做的办法 | 仍挡不住什么 |
| :-- | :-- | :-- |
| 自己给自己打高分 | 本人评价先独立提交，不先提示“打高分多得刻”；只相对本人基线，单方高分不能自行取得完整创造资格；缺其他来源时待核实 | 长期伪造自述可能同时污染模型输入，不能因模型同意就算双重证据 |
| 老师学生串通 | 将两者同向虚高而实测或后续趋势不支持的情形单列；权重方案必须做“双方一起撒谎”的压力试算；加入不依赖两人口头评分的重复性核对 | 三方若都受同一份伪造资料控制，纯软件无法证明真实改善；不能承诺根除串通 |
| 重复申领、跨老师与家人重复记 | 同一人同一事实只记一次健康创造，老师备份不重复；不同老师的同一改善不多次创造；不同家人分开，钱账一家一本不等于健康价值一家一份 | 多账户是否属于同一真人，现有身份签名不能证明；未解决就列为启用风险 |
| 挂机、拖长问诊、频繁空问诊 | 核对实际投入而非页面存活；同一次按时长或按次择一，异常时长先不按大数自动流转；明示问诊流转从学生到老师、不增发 | 双方伪造投入仍可能成立，异常检测只能提示复核 |
| 刷天数、重复吃同一次改善 | 同一日不叠加，多设备重送不叠加；按已结算周期去重；上限按人累计，不能按老师、记录或设备各领一遍 | 单次日上限不能阻止长期假记录或多账户，需要同时看周期与集中度 |

上表涉及“何种证据才可入账”“跨老师如何去重”等规则，均是待发起人确认的方案，不是现在已经生效的门槛。应先拿合成攻击样例试算，再小范围影子运行；对未能识别的攻击，报告可能影响，不以删掉异常样本来美化结果。

不做“可疑就扣币／封存”。疑点先由既有师生在本地核对、保留更正说明；运营端只看合并后的复核数量与结果。需要其他人查看个案时，不能以防刷为由越过现有资料归属与授权规则。不能为证明练习而默认要求人脸、定位轨迹、连续录像或新增中心身份库。

单纯更相信老师不能解决串通，更相信模型也不能解决同源伪造；防刷强度必须与可验证证据相称。若影响首次启用的关键攻击尚无可接受边界，继续观察比先发后追回更合适。

## 7. 定值以后怎么调，已有余额怎么办

建议顺序是：**影子试算 → 发起人批准版本与范围 → 公布生效点 → 小范围实际运行 → 同口径复盘**。每套规则都能说明适用量表、权重、系数、上限、证据与缺失处理、适用范围、生效点和批准依据；模型和老师只能建议，不能静默改社区规则。

调值不必追固定日历。用持续漂移、正常人频繁触顶、某类人长期被缺失排除、误扣增多、单方影响过大等现象触发复盘；提前写明观察窗口和判别标准，避免每次看到波动就调。新候选先在同一批观察上与旧规则对跑，再用新周期检查，报告不确定性和群体差异。一次尽量只改能解释的一组，不用放大发行量掩盖测量问题。

| 余额所处阶段或问题 | 建议给发起人的选项与默认建议（均待拍板） |
| :-- | :-- |
| 现在：从未启用 | 观察不是余额。建议不追溯铸造内测期康币；若另给初始额度，作为单独决定，不伪装成测量所得，也不从钱账兑换 |
| 正常调权重、日系数、上限 | 建议只管生效点后的新观察周期，已有刻数和历史事件保留；旧周期按事先公布的归属规则结算，不挑对本人有利的版本 |
| 尚未结算的跨版本周期 | 建议生效点切在周期边界；无法齐整时先指定整周期归属，不在同一段改善上混用两套规则或重复结算 |
| 历史重复、计量错误或查明伪造 | 与普通调参分开处理。先核实事实与可用证据，再提出可追溯的更正／冲正，原事件不覆盖；是否追偿、允许何种负余额由发起人决定，不自动全盘重算 |
| 发现坏规则需要暂停或回退 | 停止新入账，保留观察与已发生记录，公布暂停点；回退只对随后有效周期使用获批版本，不抹除已发生流转；影响与补救另行裁决 |
| 想重定单位或压缩全体余额 | “一刻”的单位不应随普通权重调整漂移。全体折算、到期清零、回收或重新分配属于另一次重大决定，本方案不预设 |

未来日系数改变会影响旧余额的相对稀缺性，即使不改旧账也会有分配影响；摘要要对照现有持有者、新参与者与老师端的变化，不能说“历史数字不变就完全没影响”。若形成负余额或影响留在社区的资格，也需单独明确规则和救济，不从康币试运行自然推导封存。

## 8. 交给下一张卡的东西

本方案认可后，先补观察口径、缺失与重复性核对、仅汇总的试算材料，再收够可用数据；不是先填规则表。第一版定值的最终交付是一页实际数据摘要、候选表、攻击与误扣试算、明确的启用及余额裁决，由发起人拍板。

本文未修改任何生产 null、保留期限、隐私或封存规则，也未规定实际权重、日系数、扣减额、按次额、上限或余额政策。文中观察排期与统计演算数值只用于说明研究工作量；涉及康币的选择仍全部待定。
