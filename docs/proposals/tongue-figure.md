# 舌象图的样子：看得懂，也看得出哪里没画准

状态：方案草案，待发起人与 Claude 审阅；只写样子和结构，不是已实现功能或编码卡。

作者：Codex｜日期：2026-10-18

依据：[V2-08 舌象抽象分级](../tasks/v2/V2-08-tongue-ladder.md)、[第二版结构图](../product/v2-structure.md)、[发起人决策记录](../../team/decisions.md)中“抽象是学习的过程”“只留最新一张裁剪图”等条目。文中例子全部虚构，只讨论外观表达，不解释体质或推断疾病。

## 1. 一张图要回答什么

学生一眼认得这是自己的舌象记录，老师一眼找得到候选特征和不确定项。示意图把已知外观画清楚；裁剪图留作对照，允许老师说“这项不像”。不把示意图做成写实照片，也不把画得漂亮当成判断准确。

当前按 V2-08 第一级设计：只有舌头的裁剪图与候选示意图同时出现，老师说了算。镜子页标“仅供自己对照”；老师审阅前标“模型候选”，改过但尚未签字标“老师已调整 · 未签字”。签字后按签字病历展示老师定的值，不把模型原值覆盖成“模型一直判断正确”。

不增加“健康分”“准确率百分比”或“正常／异常”红绿灯。是否升级到只留示意图由后续安排决定，不因几次看起来相似自动隐藏裁剪图。

## 2. SVG 示意图怎么画

### 轮廓与图层

采用正面平放的简洁舌形：上端是舌根方向，下端是圆钝舌尖。舌体一层底色，舌苔一层覆盖，齿痕在边缘，裂纹在表面；白底、细而清楚的轮廓，不画牙齿、嘴唇、鼻子、脸或拟人表情。

图内不加脏腻纹理、强高光或立体阴影，避免把画法当作真实特征。舌形胖瘦只作概括，不拉长、压扁去硬贴照片。没有轮廓把握时用通用舌形，图下注明“舌形不确定”。所有图示与特征值一一对应，不能画出没有记录的细节。

| 特征 | 看起来怎样 | 图旁的短文字与边界 |
| :-- | :-- | :-- |
| 舌色 | 舌体底色使用淡白、淡红、红、绛、紫的有限色板，露出的边缘能看见底色 | 写“舌色：淡红”等名称；色板是类别示意，不承诺复现照片颜色，不使用门面主题色替代 |
| 苔色 | 在舌面中央画一块平缓覆盖层，白、黄、灰、黑各有固定色；轮廓浅描边，让白苔在白底上也可辨 | 写“苔色：白”；色块位置只作通用示意，不凭一个苔色值猜测分布范围 |
| 苔厚 | 薄苔的覆盖层较透，能透出舌体；厚苔的覆盖层较实，底色更少露出；“无”时不画覆盖层 | 必须同时写“苔厚：薄／厚／无”，不只靠透明度；厚薄不以更黄、更黑表达，不画成凸起肿块 |
| 齿痕 | 在已知侧缘画少量平缓内凹，边缘不断裂，不画外凸锯齿或一排牙齿 | 写“齿痕：有／未见／不确定”；图表达有无与大致区域，不暗示精确数量或深浅 |
| 裂纹 | 在已知区域画细的深色实线，保持与舌体轮廓可区分；线不画成出血、伤口或黑色深沟 | 写“裂纹：有／未见／不确定”；只知道区域就用简短标记，不编造复杂走向、分叉和深度 |

齿痕和裂纹若只知道“有”，不知道位置：只在文字中写“有，位置不确定”，不在图上随便安一个位置。已知某处有、其他处未知时，只画已知处，文字补“其余不确定”；不把没画到的部分读成“没有”。左右以画面左右称呼，图例写“按画面方向”，不混称为身体左右或暗中镜像。

首版使用一套稳定图例：齿痕看边缘凹口，裂纹看内部细线，苔看面状覆盖。图下注释和特征表负责说明，避免把所有标签挤进舌头里。放大后仍用同一套记号，不凭空增加细节。

### “不确定”是一项状态

不确定与“无”“未见”分开，不能画成正常值，也不能把它变成浅一点的“有”。具体建议如下：

| 不确定的是 | 画法 | 必须能读到的文字 |
| :-- | :-- | :-- |
| 舌色 | 中性灰底，旁边有小色块说明“灰色为占位”；不套用紫、灰黑等真实类别颜色 | “舌色：不确定” |
| 苔色 | 覆盖层仅用虚线围出通用位置、不填实色；虚线只表示这一层待定 | “苔色：不确定” |
| 苔厚 | 不用薄或厚的透明度作判断；以虚线覆盖区占位，已知苔色留在文字旁的小色块 | “苔厚：不确定” |
| 齿痕、裂纹 | 该未知项不画凹口或线；不把问号散在舌面上假装位置已知 | “齿痕：不确定”“裂纹：不确定” |

图例只需一行：“实线／实色：候选特征；虚线：待定区域；灰底：颜色未定。”这些形状用法固定，不能同时拿虚线画确定的裂纹。整图未知时给通用轮廓和“暂未看清”，不生成一张看似完整的正常舌象。

文字应始终可见：学生先看到一行摘要，如“舌色淡红 · 白苔、薄 · 齿痕不确定 · 裂纹未见”，需要时展开逐项看；老师直接看到逐项内容。不能仅靠悬停说明、颜色差异或小问号辨认。

### 光线偏色时

出现 V2-08 的光线偏色标记时，在两张图共同标题下显示 **“颜色仅供参考”**，舌色、苔色两行也带“待核对”。不是在页面底部藏一句通用免责声明。

图仍按候选值画，并保留“模型候选”来源；不自动调白平衡、美化裁剪图或把偏色猜成另一个舌色。若颜色本身判断不了，按上面的不确定画法，不硬给颜色。提示不自动否定形状、齿痕和裂纹，也不暗示这些项已被确认。

“颜色仅供参考”不能只因老师修改了特征而消失：老师可能只是选定记录值，照片光线并未改变。只有新的对应拍摄没有该标记时，新的图对才不显示这条提示；旧记录的拍摄状态仍如实显示。

## 3. 裁剪图和示意图怎么并排

固定左边“舌头裁剪图”、右边“示意图 · 模型候选”，两边都只显示同一次拍摄、同一人的内容。日期／时辰、本人或家人放在整组标题上，老师端还标明学生称呼。不能把昨天的裁剪图配今天的特征图。

```text
本人 · 今天 · 巳时
颜色仅供参考                    ← 有偏色标记才出现
┌──────────────┬──────────────┐
│ 舌头裁剪图   │ 示意图       │
│              │ 模型候选     │
│              │              │
│ [仅舌头照片] │ [简洁舌形图] │
│              │              │
└──────────────┴──────────────┘
                 [放大对照]
舌色  淡红 · 待核对
苔色  白   · 待核对
苔厚  薄
齿痕  不确定
裂纹  未见
仅供自己对照                    ← 学生镜子页
                         [重拍]
```

两张图用相同中性背景、相同大小的图框；舌尖朝同一方向，舌体显示高度接近，留边相近。照片完整装入图框、保留比例，不拉伸、不再次裁掉舌缘来凑大小；示意图也不照着照片宽度强行变形。若拍摄歪斜，保留可辨的实际朝向并说明，不能为了对齐而悄悄镜像。具体旋转校正不在本方案内。

手机竖屏首屏保留左右两格；标题可换行，特征表放到图下，避免把小图挤成一条窄缝。在常见手机宽度上，每幅图以约 140–160 像素见方作排版起点，这是可读性建议，不是图像处理规格。宽屏加大两格，不拉开成难以比较的两端。

“放大对照”打开更大的同一图对：横屏或宽屏继续并排；窄屏、放大字号时可在固定图框切换“裁剪图／示意图”，切换时保留同一记录和观察区域，提供清楚的返回。默认不靠左右滑动猜还有另一张图，也不用透明叠加、闪烁动画或相似度分数取代并排。

老师看图后在下方点选特征改值，示意图随草稿更新，裁剪图保持原样；同一行短标“模型：不确定 → 老师：有”。不要求老师点出每条裂纹的坐标，不新增一轮单独的图形签字，仍由既有病历签字流程确定最终值。哪些差异进思想指纹以及如何计数沿用 V2-08。

学生不必每天回答“像不像”，老师也不必每张图打相似度分。通过“具体哪项改了”学习，不给用户再加一份问卷。

### 裁剪图不在时

镜子只留最新一张裁剪图，历史特征仍按既有保留规则展示。打开旧条目时，如对应照片已覆盖，显示“这次的裁剪图已被新图替换”，只展示该次示意图；不能借用最新照片拼成一对。因期限删除、尚未收到或加载失败要分别说明，不一律写“图片不清楚”要求重拍。

本方案不改变原图当场清掉、镜子新裁剪图覆盖旧图、问诊裁剪图随既有保留期限清理的规则，也不新增图像档案或上传路径。

## 4. 拍照提示怎么说，怎么出现

拍前默认只给一句：**“自然光下，关掉美颜，舌头轻松伸出来拍一张。”**

这句放在拍照按钮附近的普通说明中，不弹窗、不朗读、不要求勾选。每次进入拍照区可看见，但成功后不再占着结果页；“怎么拍更清楚”作为可选展开，补充“让整个舌头在画面里，看清两侧和舌尖”。不要求先买补光灯、校色卡或反复做准备动作。

失败时沿用“一个原因 + 一个动作”，在原位置给一句提醒和一个“重拍”按钮，不清空问诊文字、不弹连续警告、不把模型分数丢给学生。

| 看见的情况 | 一句话提示 | 结果页怎样处理 |
| :-- | :-- | :-- |
| 舌头太小，或未能找到舌头（V2-08 已有失败条件） | **“没拍清舌头，请靠近一点重拍。”** | 本次不生成记录；没有旧图时不画一个假结果 |
| 明确知道是模糊，且已有能力区分该原因时 | “这张有点糊，拿稳手机再拍一张。” | 不把“靠近”当成所有失败的万能建议 |
| 只有颜色偏了，其他内容可用 | “颜色仅供参考”旁提供次要入口“换个光线重拍” | 继续展示候选结果，不强迫重拍 |
| 某一特征看不准 | 直接显示“齿痕：不确定”等 | 不因一个不确定项让学生一直重拍 |
| 模型或网络暂时不可用 | “暂时没处理好，恢复后继续。” | 不归咎于拍照；只续做已有规则允许保留的任务，不为重试延长原图保存 |

首版只要求已有条件能可靠触发的提示，不为了文案新增一套清晰度、曝光或颜色判定算法。原因分不清时用“这张没看清舌头，再拍一张试试”，不要确定地断言学生离得太远或光线有问题。

同一次失败只出现一条提示，学生点击重拍再给拍照入口；重复失败不叠加长教程或催促，允许“稍后再拍”，回到原页面继续可做的事情。不默认提交失败图或沿用旧图冒充新图；尚未完成的新记录也不算今日已拍。

如果已有上一张有效记录，失败重拍不把它抹掉；清楚保留原来的日期／时辰，待新的有效裁剪图产生后再按覆盖规则替换。这里“保留上一张”指已有有效裁剪图，不是保留本次原图。

## 5. 审阅时按这几组走查

1. 同样白苔，一张薄、一张厚：苔色名称相同，覆盖程度不同，文字明确；厚苔不会变成“黄苔”。
2. 齿痕“未见”和“不确定”：前者写未见，后者明确待定；没有凭空长出的凹口。“有、位置不确定”只写文字，不乱点位置。
3. 舌色未知、苔厚未知：灰底和虚线都有说明，不会误读为灰苔、薄苔或裂纹；隐藏颜色也能靠文字读懂。
4. 光线偏色：学生和老师看见同一条“颜色仅供参考”，老师改值后拍摄提示仍在；重拍不被强制。
5. 手机上看两张同次图：舌缘完整、方向可比，点放大能看；换到家人或历史条目不串图，旧图已覆盖时如实说明。
6. 老师修改后，示意图和特征表一起变化，裁剪图不变；学生镜子里的候选结果不会变成已获老师确认。
7. 拍摄失败、局部不确定和网络失败各有对应提示；可稍后再拍、不增加新记录、不清空其他输入。

以上是设计走查场景，不是已经通过的实现验收。待审重点为：图形与“不确定”的固定图例、左右并排及放大方式、拍前一句与按原因重拍的文案。认可后由 Claude 拆卡；颜色校正、精细轮廓拟合、自动升级与存储规则调整不在本方案范围内。
