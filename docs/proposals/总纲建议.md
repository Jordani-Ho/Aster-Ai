# 对总纲的建议：把从《知衡宪章》沿袭来的概念拿出来重新推

> 写给总架构对话框。作者：知衡的技术合伙人（Claude）。总纲采纳或否决以后，这份文件就删掉。

## 问题在哪里

总纲是最上一层，医（知衡）是下面的一个子纲。按“下一层只能细化上一层”，概念应该从总纲往下流。

但现在的总纲里，有不少概念是从知衡的《宪章》往上搬的：先在一个中医产品里长出来，再放大成所有圈子的规矩。这是倒过来了，会有三个后果：

1. **医的形状压到衣食住行上。** 衣（形象）、住（风水装修）、行，本来不必带着中医的眼光和医的严谨。
2. **宪章带着法律文件的底色。** 它当初的写法考虑了“给监管部门和投资人看”，这和总纲 二之一“不写成法律文件的样子”正好相反。
3. **概念的来历说不清。** 一条规矩如果只是“知衡当初这么定的”，以后各圈要改它时，就找不到从根上推它的理由。

## 先分清两种文体（发起人 2026-10-18）

- **经**（信仰、哲学）：记叙文，讲故事，像所有宗教经典那样。知衡的《宪章》属于这一类，已改名《社区起源》。
- **纲**（律法）：每一条都能写成代码、能检查。

所以总纲里每一句都可以先过一道检验：**它能不能写成代码、能不能检查？** 不能的（例如“不讲天道”“天地只给予，不要求回报”“智能体像一颗受精卵”的比喻部分），是信仰和故事，建议挪到总架构自己的一份记叙文里（比如《缘起》），总纲只留能执行的部分。

## 建议的做法

总纲只留三样根：**阴阳一体的人、关系（学与换）、天地人**。每一个其他概念，都要能从这三样根里推出来。推得出来的，就用中性的话重新写；推不出来、只在医里成立的，就挪到医纲去。

## 逐条清单

| 总纲里的概念 | 来历 | 建议 |
| :-- | :-- | :-- |
| “代码即法律”（开头、二之一） | 宪章第十九条，原意是“规则写进代码、触发即执行、不看人情” | **删掉这句口号。** 它本身就是一个法律比喻。总纲要说的其实是“律写进智能体，智能体照着做”，直接这样说就行 |
| 律 1“对外承诺只能本人确认，不能代签” | 宪章“真人签字”：老师签病历 | **保留，但从“阴阳一体”重新推：** 智能体是人的阴面，可以替人做决定；但对外的承诺要落到现实里的阳面，所以由本人确认。“签字”是医的说法，总纲里用“确认” |
| 律 3“平台不经手钱和货” | 宪章第十条，支付去中心化、康币 | **保留，改从第七节“没有中心”推出来**（经手就是坐到中间）。康币相关的说法留在医纲 |
| 律 4“原始资料留在本人手里” | 宪章“天地三层呈现”“数据主权归本人” | **保留，但去掉“原始资料 / 抽象知识 / 个性化标识”这套医的分法**，只说“只交出对方需要的那部分” |
| 四、天“时辰按当地太阳时，节气按天文时刻” | 知衡的天时实现 | **挪到医纲和食纲。** 总纲只说“天 = 当地的时间与时节”；用时辰节气，还是用钟点季节，各圈自己定 |
| 二之二“健康在衣食住行之上”“健康是一切决定的检验” | 知衡的出发点（治未病） | **请发起人判断。** 我的看法：总纲的根是“平衡”，健康是医看平衡的那一面。衣（好看、得体）、行（自由、相聚）有它们自己的平衡，不一定都要回到“身心有没有更健康”。如果把健康放在最上面，等于让医统领了衣食住行 |
| 三、学的三层“知识库 / 老师 / 学生” | 宪章“四种角色”：老师、老师智能体、学生、学生智能体 | **保留结构，换中性的名字：** “教的一方 / 学的一方”。“老师 / 学生”是医里的叫法，衣里可能叫“造型师 / 客人”。另外，医里的老师是真人、认得学生、替学生存病历，这和总纲“老师只需要参数”不一样，已写进医纲，总纲不用管 |
| 三、“学没有考试，也没有回音” | 不是来自宪章（宪章里有公示栏评价，正好相反） | 保留。医纲已经照这条，把“本人感受”留在了本机 |
| 七、没有中心 | 发起人一贯的主张，也写进过宪章第二章 | 保留。它的根在发起人自己，不在宪章，已经从“平衡天然排斥中心”推出来了，推得很好 |
| 五、三条流里的“资金流：钱以及虚的价值” | 知衡的康币 | 保留“钱”。“虚的价值”要不要进总纲，等医里的康币观察出结果再定；现在先写成“各圈可以有自己的价值尺度” |

## 需要发起人拍板的只有一条

“健康在衣食住行之上”要不要留在总纲。其余各条，总架构可以直接照改。
