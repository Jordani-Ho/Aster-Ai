# 医纲

> 知衡是总纲下“医”的一个子纲。纲是律法的文体：每一条都能写成代码、能检查。我们信什么、从哪里来，写在《社区起源》里，不写在这里。
> 总纲（`docs/依据/总纲.md`）说过的，这里不再重复；这里只写医自己的东西。下一层只能细化上一层，不能违背上一层。
> 总纲说“严只在医”。医人命关天，所以医有几条自己的律，比总纲严；这些律只在医里适用，不加给衣食住行。

## 一、医里的角色

| 角色 | 能做什么 | 不能做什么 |
| :-- | :-- | :-- |
| 老师（真人） | 签字、定方案、定保留期限、记钱账、改门面 | — |
| 老师智能体 | 起草病历和方案、整理钱账草稿、按老师的话改门面配置 | 签字；确认入账；改律 |
| 学生（真人） | 发问诊、照镜子、打卡、确认换机关系 | — |
| 学生智能体 | 采集和整理学生的话、抽象舌象、提醒作业、照着规则判断“这段时间怎么样” | 替学生发问诊（要学生点确认）；把本人感受发出去 |
| 家里的管理人 | 为家人开子账户、代家人问诊、管一家一本钱账 | 动别家的账 |

- 医里的老师是真人，认得自己的学生：病历由老师签字，老师端保存保留期内的完整病历，师生互为备份。知识库和插在智能体上的“技能型老师”只拿参数。
- 每个学生的方案由老师单独签发，不共享动作库；作业挂在学生已有的习惯上。

## 二、医的律

总纲的五条律在医里照样守。医另外加这几条，只在医里适用：

1. **就医提醒常在，社区不判断急症。** 社区是公共场所，只有提醒的责任。问诊页顶端始终显示同一句就医提醒（急症请立即去医院或拨打当地急救电话，别等老师回复）和心理援助热线的提醒（只写名称，不写号码），不能关，不拦截发送。智能体和代码都不按学生说的话判断是不是急症、是不是自伤，不弹提醒、不打标记、不排先后；判断是老师的事。
2. **签字只能老师本人。** 智能体只起草，诊断和方案经老师本人签字才算数；签字的路径上不调用模型。
3. **他人不能冒充老师。** 归属只认签名身份，不认馆名、标志和称呼；换手机靠师生互认。
4. **原图不长期留。** 舌象等照片当场抽象：只留特征值、示意图和只有舌头的裁剪图（认不出是谁）。原图在手机上暂存多久是“数”，现在是当场清掉。
5. **感受只留给自己的智能体。** 学生自己感觉怎么样，只存在学生本机，老师和社区都拿不到。
6. **抽象一步一步来。** 模型看不准的就说“不确定”，老师说了算；模型跟着每位老师学，长期和这位老师一致了，才升一级。

## 三、医的数（运营中调）

| 数 | 现在 | 谁定 |
| :-- | :-- | :-- |
| 记录保留多久 | 默认 90 天，可设 30 天到 3 年 | 每位老师 |
| 长期留下的 | 最新方案、作业规则、老师的思想指纹、康币观察 | 底层定 |
| 原图暂存多久 | 当场清掉（最多可到 24 小时，新的覆盖旧的） | 运营 |
| 镜子裁剪图 | 只留最新一张 | 底层定 |
| 康币规则数值 | 全部未定（null），只观察、不发康币 | 发起人 |

## 四、两本账

- **钱账**：学生在社区外把钱付给老师，老师对自己的智能体说一句话就记上；老师核对后亲手确认入账，确认这一步不经过模型。钱账只在师生之间，平台不经手。
- **康币账**：康币是健康价值的尺度，不是价格。单位“刻”（15 分钟）；康币 = 时间 × 效果。效果由**老师判断**和**智能体实测**两方来量；本人感受只留给本人的智能体，不进康币。内测期间只观察、不发康币；规则调整只管以后，已有余额不重算。
- 钱和康币分两本账，不互相兑换。

## 五、师承

- 老师可以指定一位接火人，以最后一次指定为准；老师智能体交给接火人后改名“某某门智能体”，**不能用原老师的身份签字**。
- 学生可以随时离开某位老师，不需要理由；离开后学生本机的资料不受影响。
