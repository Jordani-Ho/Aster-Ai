# 医纲

> 知衡是总纲下“医”的一个子纲。总纲（`docs/依据/总纲.md`）说过的，这里不再重复；这里只写医自己的东西。下一层只能细化上一层，不能违背上一层。
> 总纲说“严只在医”。医人命关天，所以医有几条自己的律，比总纲严；这些律只在医里适用，不加给衣食住行。

## 一、医照看什么

1. **医照看的是结果：人的身心状态。** 衣食住行是手段，医看它们有没有让人更平衡。
2. **知衡管的是“未病”。** 亚健康、习惯、作息、情志。根是平衡（中医的“中”就是中庸），难是坚持。
3. **自己是自己最好的医生。** 每个人是自己身心的第一责任人；老师和智能体是帮他履行这份责任的助缘，不能替代。
4. **心理健康决定生理健康。** 大多数毛病由压力和失衡而来，调身先调心。

## 二、医里的人

| 谁 | 是什么 |
| :-- | :-- |
| 老师（真人） | 传道者：把中医的思想对到一个人、一个时辰、一个地方身上 |
| 老师智能体 | 学徒和助理：学老师怎么想，替老师起草、打理门面、记账 |
| 学生（真人） | 求道者：自己照顾自己 |
| 学生智能体 | 镜子和陪练：陪学生看自己、记自己、坚持下去 |

- 老师传的不是药方，是怎么辨证地看自己的问题；老师智能体学的不是病历格式，是老师怎么思考。
- **医里的老师是真人，认得自己的学生。** 这一点比总纲“老师只需要参数”更具体：真人老师为学生签字、替学生保存病历、和学生互为备份，所以老师知道学生是谁。知识库和插在智能体上的“技能型老师”仍然只拿参数。
- 一人一套：每个学生的方案是老师单独给的，不共享一个动作库。作业挂在学生已有的习惯上。
- 多出来的步骤落在学生那边，不落在老师那边。
- 家人：自己管不了自己的人（老人、孩子），由家里的管理人代管，一家一本钱账；有能力的人自己开账户。

## 三、医的律

总纲的五条律在医里照样守。医另外加这几条，只在医里适用：

1. **急症提醒不能关。** 智能体一发现急重症信号，第一句话永远是“请尽快去医院”；只提醒，不拦截学生做别的事。自伤类给已核实的求助热线。提醒用本地规则，不排队等模型。
2. **签字只能老师本人。** 智能体只起草，诊断和方案经老师本人签字才算数；签字的路径上不调用模型。
3. **他人不能冒充老师。** 归属只认签名身份，不认馆名、标志和称呼；换手机靠师生互认。
4. **原图不长期留。** 舌象等照片当场抽象：只留特征值、示意图和只有舌头的裁剪图（认不出是谁）。原图在手机上暂存多久是“数”，现在是当场清掉。
5. **感受只留给自己的智能体。** 学生自己感觉怎么样，只存在学生本机，老师和社区都拿不到。
6. **抽象一步一步来。** 模型看不准的就说“不确定”，老师说了算；模型跟着每位老师学，长期和这位老师一致了，才升一级。

## 四、医的数（运营中调）

| 数 | 现在 | 谁定 |
| :-- | :-- | :-- |
| 记录保留多久 | 默认 90 天，可设 30 天到 3 年 | 每位老师 |
| 长期留下的 | 最新方案、作业规则、老师的思想指纹、康币观察 | 底层定 |
| 原图暂存多久 | 当场清掉（最多可到 24 小时，新的覆盖旧的） | 运营 |
| 镜子裁剪图 | 只留最新一张 | 底层定 |
| 康币规则数值 | 全部未定（null），只观察、不发康币 | 发起人 |

## 五、两本账

- **钱账**：学生在社区外把钱付给老师，老师对自己的智能体说一句话就记上；老师核对后亲手确认入账，确认这一步不经过模型。钱账只在师生之间，平台不经手。
- **康币账**：康币是健康价值的尺度，不是价格。单位“刻”（15 分钟）；康币 = 时间 × 效果。效果由**老师判断**和**智能体实测**两方来量；本人感受只留给本人的智能体，不进康币。内测期间只观察、不发康币；规则调整只管以后，已有余额不重算。
- 钱和康币分两本账，不互相兑换。

## 六、师承

- 老师智能体是老师思想的容器，是师门的火种，不是平台的资产。
- 老师可以指定由谁接火；接火的人延续它，但不能冒充原老师签字。
- 学生始终可以选择跟随、转师或离开，不需要理由；学生的资料始终在学生手里。
