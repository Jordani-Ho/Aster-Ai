知衡落地手册

写给帮老师把知衡装起来的技术人员 · 2026 年 10 月

知衡不需要说明书：老师和学生打开就能用，用的过程中自己摸索。这份手册只讲一件事——怎样把它装起来、连起来。

一、整体是怎么连的

每个馆独立一套

阿慈养生馆和小黄运动馆各装一套，互不相干。一套里只有一位登记的老师和他邀请的学生。

二、国内网络先处理好

  • 代码：GitHub 公开仓库 Jordani-Ho/Aster-Ai，部署文件在 deploy/home/。GitHub 慢可下载压缩包。
  • Docker 镜像：先配好国内镜像加速源。
  • 编译：中继在容器里编译 Rust（10 到 30 分钟），为 crates 配国内镜像；npm 也可配国内镜像。
  • 大模型：不用在服务器上配，老师和学生在应用里各自填自己的钥匙。

三、两种装法，任选一种

A：老师自己的电脑B：云服务器
适合先试用长期使用
需要Windows + WSL2 Ubuntu，或一台 Linux 电脑；电脑要一直开着一台 Linux 云服务器（2 核 4 GB 够用）+ 一个域名
对外入口隧道（脚本默认用 Cloudflare 临时隧道，网址每次重启会变）两个子域名 + Caddy 自动 HTTPS，网址固定

两种都先装好：Docker（含 compose）、Node 22、git、curl。

A：老师自己的电脑

cd deploy/home
cp .env.example .env
./quick-start.sh        # 最后一行打印手机能打开的网址
./verify.sh             # 六项都应 PASS
Cloudflare 临时隧道在国内可能时快时慢。不稳定时，可换成国内内网穿透服务，把两个地址分别指向 web:8080（应用）和 relay:8080（中继，需支持 WebSocket）；或改走 B。

B：云服务器

  1. 域名下建两个子域名，都解析到服务器：app.域名（应用）、relay.域名（中继）。
  2. 编辑 deploy/home/.env： 
    APP_DOMAIN=app.域名
RELAY_DOMAIN=relay.域名
VAPID_SUBJECT=mailto:你的邮箱
  3. 生成配置并启动： 
    ./setup.sh
docker compose up -d --build relay gateway web
  4. 在同一个 Docker 网络里加一个 Caddy，负责 HTTPS 和 WebSocket，服务器只开 80、443： 
    app.域名 {
    reverse_proxy web:8080
}
relay.域名 {
    reverse_proxy relay:8080
}
  5. 验收：./verify.sh。
B 的反向代理部分还没有在国内实际走过，遇到问题请联系发起人。服务器放在哪里、要不要备案等，请老师和技术人员按当地情况自己判断。

四、装好以后交给老师

  1. 在部署机器上取一次性登记口令：cat deploy/home/data/teacher-setup-code.txt，只交给老师本人。
  2. 把应用网址发给老师。老师打开 → 选“我是老师” → 接入自己的模型 → 进“管理”→“我是这个社区的老师”→ 输入口令。
  3. 看到“社区已建立，可以邀请学生”就完成了。接下来老师自己改门面、邀请学生。

五、日常维护

要做的事命令（在 deploy/home/ 下）
停止（数据保留）docker compose down（A 加 --profile quick）
重新启动A：./quick-start.sh；B：docker compose up -d relay gateway web
更新到新版本git pull → docker compose build relay gateway web → 重新启动 → ./verify.sh
检查是否正常./verify.sh
  • .env、data/ 和登记口令都不要外传，也不要提交到任何仓库。
  • 部署机器上只有加密后的消息和推送订阅；病历、舌象、钱账都在老师和学生各自手机里，部署机器坏了也不丢。

六、用起来以后：有问题找谁

  • 老师和技术人员不改代码。用的过程中觉得哪里不对、哪里不顺、哪个叫法不合适，都直接告诉发起人。
  • 装不上、打不开：先跑 ./verify.sh，把没通过的那一行发给发起人。
  • 改好以后会发布新版本，技术人员按“更新到新版本”那一行操作即可。
