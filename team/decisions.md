| 2026-10-18 | **康币重新定义（讨论中）**：康币是社区里“生命健康的价值尺度”，不是价格，与法币脱钩（与法币的连接是第二步，以后再谈）。单位按“刻”（老师 15 分钟时间）。来源：本人坚持练习、遵医嘱、健康指数上升时创造；占用老师时间时按刻流向老师。钱买不到康币。康币多的是社区里的“贵族”（不必成为老师）；长期不遵医嘱、只在生病时找老师的人康币会变穷，这是本人的选择，不是老师的问题 |
| 2026-10-18 | **康币 = 时间 × 效果（讨论中）**：只花时间、天天打卡而健康没有变化，创造不出康币；效果由学生智能体按本人相对自己的变化来量（只与自己比，不与别人比）。康币的两层意义：一是能否长期留在社区（社区内的贫富之分，长期“贫穷”会被淘汰）；二是社区里人人变“富”，社区的影响力就大，进来的人就多——像比特币社区那样，以康币体现社区的价值 |
| 2026-10-18 | **康币：先打地基，再一层层盖楼**。效果由三方共同量：老师的判断、本人的感受、学生智能体的实测数据；健康是动态的，康币有进有出、可升可降。具体比例、防刷、社区总值是否公开等，靠社区运营一段时间观察后再定——平台先留好“观察接口”，规则做成可调的配置，不写死在代码里。与现实世界（法币、比特币或其他代币）的连接，也先只留接口，运营中再测试 |
| 2026-10-18 | **初期也要有现实的财务管理**：学生在社区外把钱付给老师（现金、转账），老师对老师智能体说一句话即可记账（例如“今天收到小王 100 块，帮他充进去，再送他 200 积分”）；老师智能体管老师的账，学生智能体让学生看到自己存在老师那里的余额。暂名“康币”，为将来埋下伏笔；也可以叫“积分”。未来的康币与现在的会完全不同 |
| 2026-10-18 | 钱与康币**先分两本账**（技术合伙人建议，发起人同意先这样做、内测后按各位老师的习惯再调）：钱账记充值、赠送（赠送的是钱，例如充 100 送 20 元）、扣费，定价全由老师口头决定，不分诊金药费；康币账只记健康价值。 |
| 2026-10-18 | **三层分工**：我们做底层与智能体架构（宏观结构、全部元素与基础界面），表层的个性化（界面、格式、话术、模板、提醒）由老师和学生各自的智能体去调整，不由我们统一调整；门面属于老师（如“阿慈养生馆”“小黄运动馆”），不做统一的大平台；智能体改配置不改代码，三条底线与康币社区规则不可由智能体改 |
| 2026-10-18 | “大模型”指治未病社区的基础设施。社区有三条流：信息流（重点设计信息怎么交互）、价值流（康币与钱，随信息交互而产生）、物流（药材食材等实物，对应“地”）。新增“物流（本地资源）”模块：按学生所在地告诉他哪里买得到，社区成员可分享购买地点；社区不卖东西，只指路 |
