# 时辰与节气（M1-13）

meridians.json为十二时辰/经络对应表，逐条包含来源标题与链接。数据依据任务卡及国家体育总局健身气功管理中心的对应关系说明：https://www.sport.gov.cn/qgzx/n5407/c845051/content.html 。表只用于按老师作业排程，不用于健康判断。

index.ts按设备本地钟表小时取时辰，子时23:00—次日00:59。经络与时间范围均来自数据表。
节气复用已获批lunar-typescript@1.8.6，以该库给出的节气公历日期为准，提醒在设备本地该日08:00；不转换成用户时区内天文交节点的日期。支持1901—2099，超出明确报错。按年缓存节气表，不联网。

跨年注意：该库节气表的中文“冬至”是上年冬至，本年冬至为DONG_ZHI；适配器按本年键取值，并用跨年回归测试把关。

节气日期按北京时间计算，海外学生所在时区的当天可能差一天，M1 先这样。
